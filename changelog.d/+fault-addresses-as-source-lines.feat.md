A crash on a board now shows where it happened. Every fault handler nano-ros provides prints one `nros-fault:` line with the faulting address and the return address; the FreeRTOS and bare-metal MPS2-AN385 boards print it first. `nros run` and `nros monitor` look those addresses up in the image's ELF and print the function, file and line under the fault line. They also recognise Zephyr's own fault output and the `CONFIG_NROS_FAULT_LOG` record. The ELF is the image's own; pass `--elf <path>` for an image the workspace did not build, or for a monitor opened with `--port` alone.
