`nros build --cargo-args=<args>` passes arguments to every cargo command of a cargo image, split, repeated and read from `@<file>` like `--cmake-args=`. Allowed: `--features`, `--no-default-features`, `--all-features`, `-v`, `-q`, `--timings`, `--locked`, `--offline` and `--frozen`. In a workspace, name a feature with its package (`--features=<pkg>/<feat>`). A feature the build chooses itself (the RMW, the platform, a board or capability feature) is refused: choose those in `system.toml`. `nros build --profile=<name>` builds with that profile instead of the image's `profile`, for one build, and takes the same values as `[image.<id>] profile`. A single-package cargo project now honours `profile` too; before, it was dropped without a word.
