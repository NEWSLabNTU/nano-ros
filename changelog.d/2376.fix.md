The Tutorial's C and C++ tabs run on `mps2-an385-freertos`, the same emulated board with FreeRTOS, and `nros new --lang c|cpp` refuses a bare-metal board, naming the RTOS boards of the same chip. `nros new --to <bringup>` also adds a talker's or listener's row to the bringup's contract, so a C or C++ image with two nodes no longer has its parameter store refused (issue 2376).
