Every image now serves the stock ROS 2 node interfaces by default, on every board: each node has the six parameter services (`ros2 param list/get/set/describe` reach it) and publishes `/rosout`, as an rclcpp node does. An image that cannot afford them opts out with `node_interfaces = "none"` in `[system]`, `[image_defaults]` or `[image.<id>]` of its `system.toml`. An ament package built through CMake gets `param_services;rosout` on every platform unless it sets `NROS_FEATURES` itself (an empty one opts out). `/rosout` is VOLATILE (stock is TRANSIENT_LOCAL), and a node does not subscribe to `/parameter_events`. Boards with a one-service budget, such as the Raspberry Pi Pico W, must opt out: their build stops and names the switch.
