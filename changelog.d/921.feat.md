The parameter-service buffer is derived from the contract's declared parameters instead of always being the configured `NROS_PARAM_SERVICE_BUFFER_SIZE` (4,096 B a side). The entity inventory carries each node's declaration shape as `NROS_PARAM_SERVICE_SHAPE`, and nros-node bounds the worst message of all six services against the store's resolved capacities; a size any rung states still wins, and with no declaration the 4,096 default stands (Zephyr: `CONFIG_NROS_PARAM_SERVICE_BUFFER_SIZE` now defaults to the `-1` DERIVE sentinel). The reference island's 25 declared parameters size it to 2,741 B a side at the default description capacity, and 693 B stating `NROS_MAX_PARAM_DESCRIPTION_LEN=0`.
