`SUBSCRIPTION_BUFFER_SIZE`'s help now gives the arena arithmetic the build actually uses. Above depth 1, a subscription's receive region is (depth + 1) x (buffer + 8) bytes, as `EXECUTOR_ARENA_SIZE`'s help already said. The help no longer gives the depth-1 formula `3 x buffer + 512`. Book pages, knob help, public API docs, changelog fragments and example READMEs now describe a measurement by what it was measured on, not by an internal project name. `check-user-surface-ids` refuses that name in prose on all of them; package names that contain it still pass.
