Ten more build-script sites now apply issue 1280's re-root rule, and the gate that holds them sees two populations it could not before. `nros_build_paths::env_path_list` gives a colon-separated path list the same three-valued rule a single path gets, so `nros-board-threadx` no longer compiles its kernel from one checkout and its port headers from another; the three raw `NUTTX_DIR` reads in `nros-board-common` join the sibling module that already re-rooted, so one build script stops compiling one checkout's platform port and linking another's kernel. `check-build-script-path-resolution` now also reads build-script LIBRARIES — code that runs inside every build script that depends on it — which is where seven of the ten sites were, including the zenoh-pico ABI probe's whole include set.
