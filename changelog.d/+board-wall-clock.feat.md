A Linux image can take its wall clock from its board: state `[image.<id>.knobs.clock] source = "board"` (or a fallback such as `"board,platform"`) and define `bool nros_board_wall_clock_ns(uint64_t *out_ns)`, which returns true with nanoseconds since the Unix epoch once the board's clock is set. nano-ros compiles no default for it, so an image that selects `board` without defining it fails to link, naming the function. The board gets `clock.fallback_settle_ms` to answer (asked every 10 ms), and is never asked again once the clock is resolved; the first wall-clock read waits for it. FreeRTOS images take `board` too. ThreadX and NuttX refuse `board` at build time for now.
