A Linux image can take its wall clock from its board: state `[image.<id>.knobs.clock] source = "board"` (or a fallback such as `"board,platform"`) and define `bool nros_board_wall_clock_ns(uint64_t *out_ns)`, which returns true with nanoseconds since the Unix epoch once the board's clock is set. nano-ros compiles no default for it, so an image that selects `board` without defining it fails to link, naming the function. Other ports refuse `board` at build time for now.
