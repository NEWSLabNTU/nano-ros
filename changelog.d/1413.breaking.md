The standalone `play_launch_parser` tool is retired: `nros setup --tool play_launch_parser`, the workspace module's `install-play-launch-parser` recipe and its `activate.sh` PATH entry are gone. Nothing in a build ran it — launch files are parsed by `nros-launch-resolve`, which links the same parser from the `play_launch` submodule — and it was built from a second, lagging pin. For the raw parse a `record.json` holds, run `nros-launch-resolve <launch file> --record -` (path: `nros locate tool nros-launch-resolve`). ([#1413](https://github.com/NEWSLabNTU/nano-ros/issues/1413))
