`nros build` now ends with the image's size: flash used (code, constants and initial data) and RAM used (data and zeroed data), read from the linked image's sections, so the numbers match the `size` tool's. A hosted program, such as a POSIX image or Zephyr's `native_sim`, gets no size report. Percentages of the board's capacity will follow once a board definition can state its memory budget.
