A system that declares `features = ["safety"]` on an RMW with no end-to-end integrity path (Cyclone DDS, XRCE-DDS) no longer builds. It used to build with a warning and report every received sample as valid without checking it. The build now stops and names the RMWs that carry the capability. This applies on every build path (cargo, cmake, Zephyr), and to any capability with a backend half, including `link-tls`.
