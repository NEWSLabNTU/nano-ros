`nros build` of a Zephyr image whose `entry =` names a hand-written west application now tells the application which image it is (its bringup, the image id and the entry's language), so the application no longer has to set `NROS_IMAGE_SYSTEM_DIR`, `NROS_IMAGE` and `NROS_IMAGE_LANGUAGE` itself to get its seeds and the C++ runtime a TYPED entry needs (issue 2436).
