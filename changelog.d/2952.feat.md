On every CMake platform the image's resolved `log.max_level` is now exported to the configure as `NROS_LOG_MAX_LEVEL` (0 trace .. 6 off): a compile definition on `NanoRos::NanoRos`, and so on every target that links nano-ros, plus a cache variable. C/C++ code can follow the image's ceiling with `RCLC_LOG_MIN_SEVERITY=NROS_LOG_MAX_LEVEL`, as a Zephyr app does with `CONFIG_NROS_LOG_MAX_LEVEL`. The value is resolved like the `nros-log` build script resolves it (exported variable, image row, board, platform, builtin), and a changed board level re-exports on the next build. `nros config explain --get <key>` prints one resolved knob.
