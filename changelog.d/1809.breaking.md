`system.toml` no longer accepts `[deploy.*]` or `[param_services]`; both are refused by name. Move what a block BUILT (`board`, `target`, `rmw`, `profile`, `features`) to `[image.<id>]`, a board's site facts (`[deploy.<n>.nros]`) to `[board_config.<board>]`, and WHERE nodes run (`nodes`, `launch`, `domain_id`, `locator`) to `[host.<name>]`. Replace `[param_services]` with `[system] features = ["param_services"]`. Both were deprecated since phase-383 and warned on every build; the version is now 0.6.0.
