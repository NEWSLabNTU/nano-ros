`NROS_ZEPHYR_FIXTURE_FILTER` now matches each fixture's fields one at a time, repo-relative, in both Zephyr builders. It used to match one joined line that held the checkout's absolute path, so in a checkout whose path contained `xrce` the filter `xrce` selected all 61 leaves instead of 18, and `build-(c|cpp)-.*-xrce` paired fields across the line. Every documented filter spelling selects what it did before (issue 1325).
