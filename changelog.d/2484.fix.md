The parameter services answer as stock ROS 2 does for a name the node never declared: `GetParameters`, `DescribeParameters` and `GetParameterTypes` reply with no entries instead of a filler entry of type "not set", so `ros2 param get <node> <name>` exits 1 and `ros2 param describe` prints nothing for it. A node that allows undeclared parameters still answers such a name as "not set". `ros2 param delete` of a statically typed parameter is refused as "Static parameter cannot be undeclared", and a set outside a declared range or off its step names the parameter, the range and the step, as rclpy does (`The parameter value for stepped is not a valid step. Min: 0, max: 100, value: 7, step: 5`).
