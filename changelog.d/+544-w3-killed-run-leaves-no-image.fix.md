A `nros run` killed with SIGKILL (`kill -9`, an OOM kill, a CI timeout) no longer leaves its image running. The runner already died with the verb, but the host process or QEMU guest it had started kept running, reparented to init. Every first-party runner now ties what it starts to itself: a host image or QEMU dies with the runner, and a tool that starts the image further down (`west build -t run`, `--prefix`, a command template) runs in a process group that is stopped when the runner goes.
