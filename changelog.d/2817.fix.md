A component registered on its own library (`nano_ros_auto_add_library` with `nros_components_register_node(... TYPED)`) now builds its single-node program on the linux board, and on NuttX, ThreadX and FreeRTOS, when the library has include directories or links beyond the package's `include/` and `src/`. The program links the library and takes every usage requirement the library states, where it used to compile the library's sources again without them and fail on the first header from elsewhere. A package that stated those include directories or links on the `<pkg>__<exe>` target as a workaround can drop them.
