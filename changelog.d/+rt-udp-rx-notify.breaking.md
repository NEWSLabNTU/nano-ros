A net provider must now define `nros_platform_udp_set_rx_notify`, which installs a callback the network stack calls each time a datagram arrives on a socket (RFC-0113 D4, phase-521 W4). A stack without such a hook returns `-1`. The nano-ros lwIP and NetX Duo forks add the hook, so on FreeRTOS and on ThreadX an XRCE session over UDP now reports Notify readiness: the stack wakes the executor on arrival, and the executor no longer blocks inside the transport's receive. When an RMW backend fills the `readiness_source` slot, the runtime reads that answer, not the presence of `set_wake_callback`, to decide whether the session wakes it.
