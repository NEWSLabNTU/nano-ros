An image's launch-seeded parameters now count toward its parameter store. A component that declares nothing in code and reads parameters seeded by its launch file or a `params_files` overlay got a store sized without them, and refused its own seed at boot ("does not fit the parameter store"). Each seed now takes a slot of the type the image itself reads it as.

A workspace whose C/C++ images share one runtime configure is no longer refused when one image declares parameters and the others declare none. An image the build watched declaring nothing now counts as declaring zero. An image the build did not watch still refuses, because its count is unknown.
