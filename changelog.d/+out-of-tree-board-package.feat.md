A board package kept outside nano-ros, found through `NROS_EXTRA_BOARD_PATH`, can now build C, C++ and Rust images with `nros build` without patching nano-ros. A board package ships its own CMake module (passed to the configure as `NROS_BOARD_MODULE`, with `NROS_SOURCE_DIR` for nano-ros's shared files), `cargo_config` may use `${board_dir}`, `crate_path` is relative to the board definition and defaults to its directory, and `[board.entry] type` names the board type `nros::main!` uses. Also fixed: the cargo road now compiles the FreeRTOS port assembly for Cortex-A/R ports, and the FreeRTOS trace hooks have weak empty defaults. ([details](https://github.com/NEWSLabNTU/nano-ros/pull/4186))
