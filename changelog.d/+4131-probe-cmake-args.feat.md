`[image_defaults.build] cmake_args` also reaches the metadata probe, which runs once for the whole workspace before any image builds. Put a path the probe needs there, such as `-DEigen3_DIR=...` for a library of your own: `--cmake-args=` and an image's own `cmake_args` do not reach the probe. A change to the list probes every C and C++ component again, and a removed `-D` is unset. Two bringups stating different lists are refused, naming both.
