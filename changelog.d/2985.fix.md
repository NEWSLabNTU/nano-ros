Every timer, guard condition and device event source is now counted once when an image is sized from its census, whatever route created it. Before, several Rust routes were missing from the count: a node's `create_timer_*` and `create_guard_condition`, the executor's `register_timer` and `register_guard_condition`, and a direct device registration. So was the C graph-change guard. Such an image could fail at start with "the executor's callback table is full".
