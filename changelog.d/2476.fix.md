`just zephyr setup` on an existing Zephyr workspace no longer fails after a Zephyr pin move with `Your local changes ... would be overwritten by checkout`. nano-ros's patch set edits files inside the workspace's zephyr and zephyr-lang-rust checkouts, and git refused to check out a new revision over those edits. Before `west update`, setup now saves each project's local edits to a diff under `<workspace>/.west/nros-preupdate/` and resets the project. It then re-applies nano-ros's patches to the new revision. Any edit of your own stays in that diff file, which setup names on the console. A failed update puts the edits back.
