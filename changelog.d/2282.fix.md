`nros new <ws> --board <board>` now ends with the command that starts the
image on that board. It always said `nros run <node>`, even on boards
`nros run` refuses. A board with a host or emulator target still gets
`nros run`, real silicon gets `nros flash` (the Pico W, whose Wokwi twin has
no runner yet), and a board that states neither gets `nros build` and a note
(issue 2282).
