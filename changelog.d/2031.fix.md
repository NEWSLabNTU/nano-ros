The zenoh port-row schema no longer accepts `system_libs`, `exclude` or `link`: nothing read them, so a `[port.<platform>]` row in an out-of-tree `nros-rmw.toml` that sets one now fails to load instead of being silently ignored. Delete the key; `pthread` is linked by the zenoh build itself. The book chapter `internals/zpico-build.md` now documents the schema that exists.
