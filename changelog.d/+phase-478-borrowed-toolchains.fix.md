A checkout no longer silently uses another checkout's tools. `scripts/bootstrap.sh shell-doctor` and `just doctor` now FAIL when the `nros` on PATH belongs to a different nano-ros checkout, and name both trees and `just setup-cli`; `scripts/bootstrap.sh` builds this checkout's CLI instead of accepting the borrowed one. A Zephyr configure refuses a Zephyr SDK that lives inside another checkout (`-DNROS_ALLOW_FOREIGN_SDK=ON` downgrades it to a warning). `scripts/bootstrap.sh --dry-run` no longer builds the CLI: a marker comment inside a line continuation had split its `run_cmd` call in two (phase-478 I1, I2).
