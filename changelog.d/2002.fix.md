`QoSProfile::px4()` (`QOS_PROFILE_PX4`) no longer states automatic liveliness.
The XRCE backend it is meant for honours no liveliness and has refused a
stated one since #1329, so every PX4 companion failed to create its first
publisher with `IncompatibleQos`. It now carries the unset sentinel, like the
upstream-mirroring profiles.
