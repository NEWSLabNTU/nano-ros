`nros sync` now recovers a single-package Rust leaf whose `build/<image>/nros-cargo.toml` was deleted while its `.cargo/config.toml` still includes it. Before, if the metadata probe had to run again, it failed on the missing file, sync stopped before the step that writes the file, and every later sync failed the same way, with an error that told you to run `nros sync`. The probe no longer reads the generated settings file: sync writes that file after the probe, from the probe's own output.
