The parameter store is now sized from the parameters each launched node's code declares, as `nros configure`'s metadata probe records them, as well as from the contract's `params:`. An image whose code declared more parameters than the default store holds used to exit 250 at boot with nothing on the console. A C parameter server asked for more slots than the store has, an executor at its `max_handles`, and a component setup that fails for any reason now each say so on the console, naming the knob to raise.
