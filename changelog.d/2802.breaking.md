nano-ros no longer provisions or distributes the Arm FVP (`FVP_BaseR_AEMv8R`): the `[tool.arm-fvp]` index row, `nros setup --tool arm-fvp`, the `fvp-aemv8r-smp` board's package entry and `scripts/installers/arm-fvp-installer.sh` are gone. Install the AEMv8-R FVP from Arm (x86_64 Linux) and its runtime dependency `libatomic1`, then set `ARMFVP_BIN_PATH` (or `ARM_FVP_DIR`, or put the model on `PATH`). `nros setup board fvp-aemv8r-smp` says so and succeeds whether or not the model is installed, and `nros doctor` reports whether it is found and through which setting. A build directory configured before the model was found caches `ARMFVP-NOTFOUND`; re-configure it.
