The ThreadX byte pool now counts the stacks of an image's spawned sched tasks. `nros build` states them in the image's sizing descriptor, deriving each level's stack with the same rule `nros::main!` uses, and the pool adds them to its derived size and to the floor a stated pool is checked against. An image whose tasks did not fit used to stop at boot; it now gets a pool that holds them, and `nros::main!` refuses an image whose table spawns stacks the descriptor does not state. A build with no descriptor counts no task stacks and says so.
