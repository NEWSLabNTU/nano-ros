A hazard whose reaction is a scope path -- the shape every model play_launch resolves from a contract has -- bakes the settle and the sink of the safe state at that path's end again. The hazard table read only the reaction path's own `safe_state`, which a scope path never has, so its row carried `settle_ms: 0` and no sink, and the observer could not see the reaction land. The safe state is now the one on the node path whose `emits` publishes one of the scope path's outputs (the largest settle when several do).
