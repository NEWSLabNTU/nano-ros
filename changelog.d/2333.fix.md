`nros setup <board>` run outside a project records what it installed in the store's own lock, `~/.nros/nros-sdk.lock`, instead of writing `nros-sdk.lock` into the current directory. Inside a project, a workspace or bringup with no pin yet now counts as the project, so its lock is written there rather than in a pin file further up the path. `nros store gc` consults the store's lock wherever it runs. The Install page explains the lock.
