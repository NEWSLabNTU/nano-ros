A Rust image now gets the same rate-monotonic schedule as its C and C++ twins. When a workspace's contract states rates, its nodes put their callbacks in groups in code (`node.callback_group("ctrl")`), and `system.toml` authors no `[tasks]`, `nros::main!` derives the `derived-*` sched tasks that `codegen entry` derives. It used to run every node on one task, silently. Every road now prints the derived schedule, or one line saying why it declined (issue 2432).
