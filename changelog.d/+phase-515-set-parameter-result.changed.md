Rust: `ParameterServer` writes (`set`, `set_parameter_value`, `set_or_declare`, `declare_parameter`, `apply`, ...) and the `Executor`/`Node` parameter setters return `Result<(), ParameterError>`, as rclrs does, instead of `SetParameterResult`. `ParameterError` gains `Undeclared`. `SetParameterResult` is deprecated and goes next release: replace `SetParameterResult::Success` with `Ok(())`, `SetParameterResult::X` with `Err(ParameterError::X)`, `.is_success()` with `.is_ok()` (phase-515).
