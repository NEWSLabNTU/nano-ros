A C or C++ FreeRTOS image on zenoh now gets a 512 KiB default heap, derived the same way the Rust road derives its own, where it used to get a 3 MiB fallback. That is about 2.5 MiB less RAM per image. The C talker template peaks at about 90 KB of heap, and a larger image reads its own `nros: heap peak` boot line. An image that needs more sets `NROS_FREERTOS_HEAP_KB`, as before.
