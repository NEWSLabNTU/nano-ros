The Zephyr Kconfig help of `NROS_ZENOH_MULTI_THREAD`, `NROS_ZEPHYR_TASK_STACK_SIZE` and `NROS_ZENOH_AUTO_RECONNECT` names the tasks a zenoh image runs since zenoh-pico 1.10 (one executor thread `zpico_exec`, plus `zpico_flush`), not the retired read and lease tasks, and `NROS_ZEPHYR_TASK_STACK_SIZE` records the measured `zpico_exec` peak on S32K344 silicon (1,964 B of 4,096 B on the safety island) beside the mps2_an385 one. RFC-0110's stack table gains the silicon row.
