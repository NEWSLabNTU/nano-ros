A parameter descriptor no longer holds a copy of the parameter's name, which saves `NROS_MAX_PARAM_NAME_LEN` bytes (64 by default) in every parameter store slot. The store keeps the name once, in the parameter itself, and `ros2 param describe` still shows it. In Rust, `nros_params::ParameterDescriptor` has no `name` field, and `nros_node::parameter_services::to_rcl_descriptor` takes the name as its first argument. `ParameterDescriptor::new(name, type)` keeps its signature and still refuses a name longer than `NROS_MAX_PARAM_NAME_LEN`.
