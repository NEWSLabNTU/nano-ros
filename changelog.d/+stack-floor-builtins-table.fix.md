The stack-floor check now has a frame for every toolchain builtin a Zephyr image links: libgcc's hand-written routines are read from a measured table keyed by the exact archive the link used, and `compiler_builtins`' hand-written routines and the C++ message glue are read from the image's own objects. Images on boards such as mps2-an385 get a floor instead of a refused walk, and a toolchain the table does not know is named in the refusal with the command that measures it.
