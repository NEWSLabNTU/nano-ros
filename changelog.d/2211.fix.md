A Zephyr Rust image whose `system.toml` names the `zephyr` board family now configures for a concrete board such as `west build -b mps2/an385`. The Rust-target check used to compare the family's native_sim triple with the target zephyr-lang-rust picked, so every mps2/an385 Rust row stopped at configure. It now checks the board that `-b` names.
