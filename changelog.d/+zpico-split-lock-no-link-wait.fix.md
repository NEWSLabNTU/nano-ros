With the zenoh split-lock TX path on (`CONFIG_NROS_ZENOH_TX_SPLIT_LOCK` with `TX_BATCH`), no publish waits behind another sender's slow link write any more. A large message's fragments, a parked batch, an express message and the periodic flush used to wait for, or write, the link while holding the transmit lock, so every other publisher waited with them; on a 921,600 baud serial link that was up to about 58 ms. Wire order, and an unbroken fragment train, are kept.
