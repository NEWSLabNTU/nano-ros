An XRCE image now notices a DDS participant that leaves the ROS 2 graph even when that participant's last `ros_discovery_info` sample never reaches it, as happens after a crash or when a busy Agent loses the sample. Once the image reads the graph (a node-name query or a graph-change registration), the session re-reads it every `xrce.graph_resync_ms` (default 5000, 0 turns it off): it drops any participant that no longer announces itself and fires the graph-change event. A departure is seen within twice that period, plus the DDS lease (20 s by default) after a crash. An image that never reads the graph is unchanged.
