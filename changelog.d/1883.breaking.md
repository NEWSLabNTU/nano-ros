The NuttX per-bringup apps template (`integrations/nuttx/apps-external-template/`) is retired, and `scripts/nuttx/stage-external-apps.sh --bringup/--image/--copy` now refuse. That road never built an image: its cargo step ran a nightly-only `-Z` flag on stable, named a `Cargo.toml` no bringup has, and linked a `nros_system_main()` nothing has emitted since Phase 258. Build a NuttX workspace image on the cargo road instead: add `[image.<id>] board = "qemu-armv7a-nuttx"` to the bringup's `system.toml` and run `nros build` (issue 1883).
