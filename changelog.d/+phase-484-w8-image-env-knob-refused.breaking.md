An `[image.<id>] env` row naming a registry knob is now refused, naming the knob's own spelling: write `[image.<id>.knobs.<group>] <name> = <value>` instead (`env = { NROS_ZEPHYR_HEAP_SIZE = "98304" }` becomes `[image.<id>.knobs.zephyr] heap_size = 98304`). Release 0.6.0 accepted the row with a warning. Env rows that name no registry knob — an application's own variables, `NROS_BOOT_REPORT`, the monitor flags — are unchanged.
