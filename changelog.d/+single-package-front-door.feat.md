`nros new <name> --board <board> --template <role>` scaffolds one package for the board you hold: the platform is read from the board, the package's `system.toml` declares one image, and the package carries a README with its build steps. The Rust bare-metal scaffold no longer writes a `nros.toml`, which nothing read. `nros new <ws> --workspace --from <package>` grows such a Rust package into a workspace: the node moves over unchanged and its `system.toml` becomes the workspace's bringup. `nros new node` packages now enable the `macros` feature their `lib.rs` uses, so they compile on their own.
