Zephyr `native_sim` C++ images link again. The per-image message-FFI staticlib is whole-archived beside `libnros_cpp.a`, and both carried compiler-rt's C intrinsics as strong symbols, so Zephyr's own `bitarray.c` calling `__popcountdi2` made every zenoh and Cyclone C++ image fail with `multiple definition of __popcountdi2`. The FFI archive now keeps only its `nros_cpp_*` surface strong (issue 2092).
