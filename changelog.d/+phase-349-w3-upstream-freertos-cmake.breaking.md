FreeRTOS boards built through CMake now compile the kernel with upstream FreeRTOS-Kernel's own `CMakeLists.txt` and take lwIP's source lists from its `src/Filelists.cmake`, instead of nano-ros's own source lists. `FREERTOS_DIR` must point at FreeRTOS-Kernel V10.5.0 or newer, the first release with that CMake. `FREERTOS_PORT` accepts upstream's port name (`GCC_ARM_CM3`) or a path under `portable/` (`GCC/ARM_CM3`), and a vendor port dropped into `portable/` is built through upstream's custom-port hook. A host project that already defines `freertos_config` keeps it, and definitions that change `FreeRTOSConfig.h` now go through `nros_freertos_config_define()`, so the port's own sources see them too (phase-349 W3).
