`nros new <ws> --board qemu-cortex-a53` now scaffolds an image that reaches
the router. The board package states the network stack, the QEMU address, a
random source and aarch64-sized stacks, and before this the image built with
no network stack. `nros new <ws> --board nucleo-f767zi-zephyr` and
`--board rpi-pico-w-zephyr` now write the board's serial locator. Before this
they wrote none, and the image dialled TCP with its IP stack turned off
(issue 2290).
