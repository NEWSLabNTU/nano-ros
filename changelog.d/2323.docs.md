Working offline's package step now downloads in a plain `ubuntu:24.04` (or `ubuntu:22.04`) container with the ROS 2 apt repository added, and with apt told that nothing is installed, so the set it carries includes ROS 2 itself and the base packages a plain Ubuntu already has (606 packages, 227 MB for Jazzy). One `apt install ./debs/*.deb` then installs everything on the offline machine.
