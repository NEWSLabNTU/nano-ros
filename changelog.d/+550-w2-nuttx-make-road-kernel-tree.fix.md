The NuttX make road (`CONFIG_NROS=y`, `integrations/nuttx/`) builds without `NUTTX_DIR` in the environment. Its cargo build now names the tree make is building, `$(TOPDIR)`, as the kernel (`NUTTX_DIR`, plus `NUTTX_APPS_DIR` and the include root), so zenoh-pico compiles against that kernel instead of stopping with `nuttx-kernel: not provisioned anywhere this build looks`, or, in a checkout with the NuttX submodule initialised, compiling against nano-ros's own kernel. The tree make is building wins over an exported `NUTTX_DIR`.
