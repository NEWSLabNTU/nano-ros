The NuttX build no longer writes its lock, configuration markers and export snapshots inside the vendored NuttX tree, so that submodule no longer reads as modified after a build. They now live in a `<tree>.nros-build/` directory beside it; `NUTTX_EXPORT_DIR` still overrides the location, and the build removes the old in-tree files. ([details](https://github.com/NEWSLabNTU/nano-ros/pull/4280))
