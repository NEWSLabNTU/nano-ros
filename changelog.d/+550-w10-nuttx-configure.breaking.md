A NuttX build now requires the kconfig-frontends tools (`kconfig-frontends-nox` on Debian and Ubuntu). The board kernel configs are fragments over upstream NuttX configs, which NuttX's own `tools/configure.sh` expands and resolves, and configure.sh runs `kconfig-tweak`. The build no longer installs kconfiglib into a private venv when the tools are missing; it stops and prints the install line instead. `nros setup <nuttx board> --sudo` installs the package. If you configured a kernel by copying a board defconfig to `.config`, run `tools/configure.sh` on it instead.
