`nros check <package>` checks a runner, command or board package you wrote.
It works out the package's kind and runs that kind's check. A runner or
command is built, located and checked against this `nros`'s protocol. A board
has its descriptor, announcement, network and Zephyr projection resolved. The
`nros new` and `nros board new` scaffolds now name it as the next step instead
of `nros dev … check` or `just check fast`. `nros check <path>` and
`nros check --workspace` are unchanged, and `nros dev runner check` and
`nros dev command check` still work (issue 2294).
