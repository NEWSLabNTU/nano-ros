`nros locate nano-ros` prints the nano-ros SDK root outside a checkout too — the directory a host build tool needs for nano-ros's CMake modules, Zephyr module and board descriptors. It needs no index or network, and in a project pinned to a nano-ros version (`nros-toolchain.toml`) it prints that version's root, so projects on different versions each get their own. `--why` names the version and pin that answered; `--project` naming a project pinned to another version refuses instead of printing the wrong root.
