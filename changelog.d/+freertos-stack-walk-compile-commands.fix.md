A FreeRTOS, NuttX or ThreadX C or C++ image now writes `compile_commands.json` when its stack floor is checked, so the build-time stack walk can type the image's C call sites instead of assuming each one may call any function C can hold. The new FreeRTOS C talker project walks 130,424 bytes, down from 147,060. A project or `-D` that sets `CMAKE_EXPORT_COMPILE_COMMANDS` either way keeps its choice.
