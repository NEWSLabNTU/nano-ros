The stack-floor check no longer counts a function's address as taken when only code the link discarded takes it. Each image's force-link table of every C and C++ API export made the whole API look reachable through every C function pointer, so an image linking the C++ API was walked at about twice its floor. realtime-c's FreeRTOS image now walks 92 KB instead of 188 KB. A function whose address the image itself holds still counts, even with no relocation for it, as with Zephyr's generated interrupt table.
