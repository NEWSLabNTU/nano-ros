The Zephyr QEMU boards (`mps2-an385-zephyr`, `qemu-cortex-a53`) state their QEMU facts in `[board.run.qemu]`, which gains an `smp` key. `nros run` still boots a west-built Zephyr image through the `west` runner; the facts are read by the test harness, and by `nros run` when an image names the `qemu` runner itself. Each Zephyr QEMU test boot first checks them against the `run_qemu` line its own west build generated, and refuses to boot when they disagree.
