An image whose hand-written entry never initialises nano-ros can say so with `[image.<id>] runs_nano_ros = false`. Its configure then records an empty census without building or running the program on the host, and the image is sized for zero entities. Before, such a program exited 0 in census mode with no census and the configure refused, and `[census] on_missing = "warn"` was the only way past, which refused every count the census would have stated. The statement is refused on an image that is not sized by an owned entry's census. An entry that does not state it keeps the refusal.
