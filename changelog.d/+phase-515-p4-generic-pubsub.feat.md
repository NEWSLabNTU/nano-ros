C++: `rclcpp::GenericPublisher` and generic subscriptions keyed by a type name AND its RIHS01 hash: `node->create_generic_publisher(topic, type, type_hash, qos)` (publish CDR bytes with `publish_serialized`) and `node->create_generic_subscription(topic, type, type_hash, qos, callback)` (`callback(const uint8_t* data, size_t len)`). rclcpp's name-only spellings are now a compile error that names this form, since a type name alone cannot give the wire its hash (phase-515 P4).
