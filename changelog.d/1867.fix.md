`nros build` now passes `-DZEPHYR_EXTRA_MODULES=<checkout>` on its `west build` handoff. Before this fix, every Zephyr image it built against the shared store workspace (`~/.nros/workspaces/zephyr/<version>`) aborted at Kconfig with `undefined symbol NROS`, because that workspace's manifest project carries no module (issue 1258). `check-zephyr-module-binding` now also reads the CLI's Rust west handoffs (issue 1867).
