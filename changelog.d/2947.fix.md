A C or C++ node on a backend reached through the C ABI (threadx-linux, for one) now creates its `/rosout` writer: the root namespace was spelled two ways in the shim's node table, so a one-node image refused the writer. A refused publisher, client or `/rosout` writer now logs the backend's own error, and a full node table says to raise `NROS_RMW_MAX_NODES`.
