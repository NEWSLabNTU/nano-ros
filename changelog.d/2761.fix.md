An image whose entry does not include the C entry header, such as an unmodified ROS 2 C++ program built with `ROS2_MAIN` for the FreeRTOS POSIX simulator, links again: the FreeRTOS, Zephyr and NuttX board runners now call the optional network-wait hook only when the image defines it, through one shared weak-reference helper, instead of declaring it as a plain external that nothing defined.
