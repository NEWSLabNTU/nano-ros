`nros build` now keeps the native tool's output. The tool runs on a pseudo-terminal that `nros build` holds, so its colour, cargo's progress bar and its line buffering are the same as when you run it directly. Every byte reaches your terminal unchanged and is also written to `<build dir>/<tool>.log` (`cargo.log`, `cmake.log` or `west.log`), which is replaced on each build. When `nros build`'s output is not a terminal (CI, a pipe), the tool gets pipes, as before, and the log is still written. Ctrl-C stops the tool and everything it started, and `nros build` exits with the tool's own status.
