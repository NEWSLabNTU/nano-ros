An owned Zephyr west entry (an image whose `entry =` names a hand-written west application) now finds the workspace's own message packages with no line in its `CMakeLists.txt`. A generated west application and a generated CMake root put the workspace's `src/` on `NROS_INTERFACE_SEARCH_PATH`; an owned entry got nothing, so a `find_package(<pkg>)` of a message package under `src/` failed at configure unless the entry set the variable by hand. `nros build` now passes `-DNROS_INTERFACE_SEARCH_PATH=<workspace>/src` on the owned entry's west line, followed by any value you exported, the same path the census build of that entry uses.
