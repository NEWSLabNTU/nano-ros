One owned entry can now serve several images of a bringup: name it from each with `[image.<id>] entry = "<pkg>"`. `nros build` builds that package on the cargo road, writes one adapter holding every image behind an `image-<id>` feature and turns on the one it builds, and `node_features` on such an image turns on the entry's own cargo features (RFC-0071 D19, issue 2406).
