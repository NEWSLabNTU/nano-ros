Every `nros new` workspace template now writes a `system.contract.yaml` beside its bringup, not only the talker. The listener, server, client and action templates state that their node declares no parameters, so the build sizes the parameter store for the one parameter the runtime seeds, rather than for 32 parameters. On a 264 KiB board this frees about 62 KB, which is the difference between overflowing RAM and fitting.
