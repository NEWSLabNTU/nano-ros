`just build zephyr` and the test-fixture builds now stop before building when the provisioned Zephyr workspace holds projects that are behind, diverged from, or missing the commits this checkout pins. Such a build used to succeed against the wrong kernel, or fail later with errors that pointed elsewhere. The message names each project, says how it is off, and gives the one command that moves the workspace back to the pin. A project ahead of its pin is only a warning. `just doctor` reports the same check, and `just check zephyr-pin-drift` runs it on its own.
