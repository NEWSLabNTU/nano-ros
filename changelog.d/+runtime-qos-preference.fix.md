A node on a backend that does not honour a QoS policy the runtime picked for its own endpoints now still gets those endpoints. On XRCE, every node lost `/rosout` because its 10 s lifespan was refused; the runtime now drops such a policy from its own `/rosout`, `/parameter_events`, parameter and lifecycle endpoints and says so once at info level. A profile an application asks for, a launch QoS override or a declared contract is still refused, naming the policy.
