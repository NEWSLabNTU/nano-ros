RTIC and Embassy images now deliver signaled callbacks to their nodes. `ExecutorNodeRuntime::dispatch_callback` scanned only components registered through `register_node`. The `register(runtime)` seam every `nros::main!` image uses enrolls components with the executor instead, so every callback the framework dispatch task forwarded was dropped. `just qemu test-rtic-main-e2e` builds and passes again. The router it starts listens on the port its image states in `system.toml`, and a QEMU run under `tests/run-test.sh` has a deadline, so a hang is a failure instead of a pass.
