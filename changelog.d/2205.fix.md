When `nros sync` (or `nros locate tool nros-launch-resolve`) cannot find `nros-launch-resolve`, it now lists every place it looked, with the path at each, and how each install track provides it: the checkout recipes, the release asset, or `NROS_LAUNCH_RESOLVE=<path>` for a resolver built anywhere else. Before, it said only that the resolver was "not next to the `nros` binary".
