Rust: the node is the parameter receiver, as in rclrs. `Node::declare_parameter::<T>(name)` returns the `ParameterBuilder` (`.default(v).mandatory()`), `Node::use_undeclared_parameters()`, and `get_parameter` / `set_parameter` / `describe_parameter` / `list_parameters` / ... are on `Node`. The bare `Executor::declare_parameter`, `get_parameter`, `set_parameter`, `parameter` etc. are deprecated (one release); call them on the `Node` that `create_node` / `node_mut(id)` returns (phase-515 R10).
