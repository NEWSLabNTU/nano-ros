`just gc-shared-cargo` now looks inside a live shared Corrosion store: a per-build-dir folder (`nros-cpp-image_<hash>`, about 1 GB) whose build dir is gone is reported, and removed with `--prune`, when no live build dir's generated build files (`build.ninja`, or `build.make` for Unix Makefiles) name it. Before, a store stayed whole while any leaf linked to it, and one grew to 410 GB. Each orphan is reported with the build dir it was compiled for; `--self-test` runs the negative controls.
