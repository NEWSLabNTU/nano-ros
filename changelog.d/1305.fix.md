Every single-package example now gets its board crate, RMW backend and runtime
crates from the generated `<pkg>_nros_selection` package, so switching board is
the one `[image.*] board` line. The last three classes moved: the copy-out
templates' Rust packages (`nros sync` in a workspace now writes a member
package's selection before its first cargo call), the bare-metal MPS2-AN385
C/C++ applications on a cargo link root (their `main.rs` reaches the board
through the selection package; the images state `panic = "platform"`), and
the ESP32-C3 examples (`nros::main!` brings `esp_hal` in from the board's
re-export, which `nros-board-esp32-qemu` now provides).
