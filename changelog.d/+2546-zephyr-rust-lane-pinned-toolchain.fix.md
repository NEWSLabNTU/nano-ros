A Zephyr Rust project made by `nros new` now builds its Rust app on the toolchain `rust-toolchain.toml` pins, as the C lane already did. Before, it used whatever toolchain rustup defaults to, so two hosts could build different code from the same template. The nucleo-f767zi Rust templates' stamped main stacks rise accordingly: 75,632 B for the action server and 74,464 B for the talker.
