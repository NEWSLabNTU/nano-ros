`nros` compiles again with `param-services`. Two callers of `Executor::declare_parameter` discarded the result that phase-428 W6 made `#[must_use]`, so every image declaring `param_services` failed to build. A refused launch `<param>` now refuses the boot and names the parameter, and a refused component parameter returns the new `NodeDeclError::ParameterRejected`. On Zephyr the capability now names `alloc` as well, so a zenoh image declaring `param_services` builds instead of stopping at nros-node's `compile_error!`. `compile-smoke` now checks `nros-c` / `nros-cpp` with `param-services`, so the host path is compiled on every pull request.
