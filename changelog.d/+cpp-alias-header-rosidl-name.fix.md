The ROS-style C++ alias header (`<pkg>/msg/<name>.hpp`) now carries the name rosidl gives it when a digit or an acronym comes before a capital: `float32_stamped.hpp` for `Float32Stamped`, `u_int8.hpp` for `UInt8`, `tf_message.hpp` for `TFMessage`. An include written against rclcpp now resolves. Code that included the old spelling (`float32stamped.hpp`, `uint8.hpp`) must switch to the rosidl name.
