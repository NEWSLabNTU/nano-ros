The `nros` feature `ffi-sync` (and `nros-node`'s) is removed. It turned on an empty feature and reached no code, so an image that named it built exactly as one that did not. The FFI reentrancy guard is the zenoh backend's own `nros-rmw-zenoh/ffi-sync`: enable it on your backend dependency. `nros` is backend-agnostic and cannot forward it.
