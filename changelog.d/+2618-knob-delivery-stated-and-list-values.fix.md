A Zephyr build no longer fails after the link step when a `.conf` fragment states a pool size above the derived one (for example `CONFIG_NROS_MAX_PUBLISHERS=13` where the image needs 11), or when it subscribes to more than one message type. The knob delivery check now checks only that each resolved value reached the compiler. Configure still reports a stated value that differs from the derived one, and the check compares the per-type bounds list the same way whichever separator it was written with.
