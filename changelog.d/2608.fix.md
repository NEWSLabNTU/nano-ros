A C or C++ metadata probe that fails (its configure fails, a target errors, or an earlier failure is cached) is now reported as a failure, naming the node, the first error line and the log. Before, the node was reported as having no probe and the image was built on default sizes without a word. `NROS_PROBE_FAILURE` picks what happens: `warn`, the default for an interactive `nros build` or `nros configure`, finishes the sync and ends with `sync: WARNING — N metadata probe(s) FAILED`, and refuses when every probe failed; `refuse` makes `nros sync` and `nros configure` exit non-zero. Any other value is an error. Set `NROS_PROBE_FAILURE=refuse` in CI and other unattended builds. (issue 2608, [#4073](https://github.com/NEWSLabNTU/nano-ros/pull/4073))
