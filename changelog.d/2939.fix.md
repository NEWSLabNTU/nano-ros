rclc's default parameter server (`rclc_parameter_server_init_default`) now starts in an image whose parameter store holds fewer than 4 parameters. It asked for rclc's default quota of 4 and was refused, even though every parameter the node declares fits; the quota is now capped at what the store holds. A quota stated through `rclc_parameter_server_init_with_option` is still refused when it is larger than the store.
