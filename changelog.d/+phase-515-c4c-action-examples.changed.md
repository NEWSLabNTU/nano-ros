The C action-server examples (every platform, and the C components in `examples/workspaces/{c,mixed}`) now use rclc's action-server shape: `rclc_action_server_init_default`, `rclc_executor_add_action_server`, `rclc_action_publish_feedback` and `rclc_action_send_result`. `rclc_action_server_init_default` accepts a NULL `support`, as `rclc_timer_init_default` does, so a C component can call it (phase-515 C4c).
