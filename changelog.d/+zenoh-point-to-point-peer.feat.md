zenoh-pico can now open a peer session with no router over a point-to-point link: IVC, and the new RPMsg link (`rpmsg/<name>` locators, the `link-rpmsg` feature) for talking between cores on an AMP SoC. Peer mode is compiled in only when an image compiles such a link, so default builds are unchanged. A board supplies the RPMsg binding through the C contract in `include/nros/rpmsg_link.h` of the new `zpico-link-rpmsg` crate. ([peer mode](https://github.com/NEWSLabNTU/nano-ros/pull/4233), [RPMsg link](https://github.com/NEWSLabNTU/nano-ros/pull/4246))
