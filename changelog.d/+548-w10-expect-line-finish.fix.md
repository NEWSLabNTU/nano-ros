`nros run --expect` (and `nros flash --monitor` / `nros monitor`) no longer stops the target in the middle of the line that matched. A target that writes one line in pieces, such as the NuttX C++ talker, used to be cut off after the first piece, so the console showed `Publishing: 'Hello` and the "matched" report named only that much. After a match the console is now read to the end of that line, for up to half a second, and the whole line is printed and reported.
