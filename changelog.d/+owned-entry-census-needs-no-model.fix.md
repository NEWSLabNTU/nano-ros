A hand-written entry package named `<image>_entry` that boots its bringup's `[[component]]` rows is no longer census-sized as an owned entry. `nros configure` tried to configure such a launch-only entry standalone for the host, which it cannot do (it relies on the workspace that adds its components), and printed a failed host build (`Unknown CMake command "nano_ros_add_executable"`) on every configure. The owned-entry census now applies only when the bringup declares no component, which is the case it exists for; otherwise the image's model sizes it, as for any image with components.
