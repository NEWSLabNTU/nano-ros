The CMake toolchain file `cmake/toolchain/armv7a-nuttx-eabi.cmake` is renamed `cmake/toolchain/armv7a-nuttx-eabihf.cmake`, after the hard-float triple it has always set. The old name stays as a deprecated file that includes the new one, so a build directory configured before the rename keeps working: CMake keeps including the toolchain path it recorded at the first configure, even when `-DCMAKE_TOOLCHAIN_FILE` names a new one. New builds should name `armv7a-nuttx-eabihf.cmake`; boards and `nros build` already do.
