The help for `CONFIG_NROS_ZEPHYR_HEAP_SIZE` lists the measured platform-heap peaks of the Zephyr C and C++ talker, listener, service and action images. The 64 KiB default for C and C++ images stays: the action images peak at 33,648 bytes, which with the 24,576-byte headroom floor needs 58,224. The help for `CONFIG_NROS_GRAPH_CACHE_SIZE` now explains how a small board with an IP link states a smaller graph cache, through `[knobs.graph] max_entities` in its board descriptor.
