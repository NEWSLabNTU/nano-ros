On the hosted ThreadX Linux port every thread now runs on the stack it was created with, as on a ThreadX board, so a host run catches a stack overflow its target would hit. A thread stack below the host minimum (16 KiB on x86_64, 128 KiB on aarch64) is raised to it, and the image refuses to start on a host whose minimum is larger than the port states. Each image prints every thread's stack peak when it ends.
