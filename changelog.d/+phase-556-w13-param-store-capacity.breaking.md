An image whose parameter count nobody states or declares now carves a parameter store of 8 slots, not 32. That is every image that serves the stock parameter services and declares no `params:` in its contract. A ninth declaration stops the boot and names `NROS_MAX_PARAMETERS`. To hold more, declare the parameters in the contract (`params:`), which sizes the store from that count, or set `[image.<id>.knobs.params] max_parameters`. Each slot costs about 8.5 KiB whatever its type, so 32 undeclared slots took 285,696 B of RAM from images that hold no parameter. On Zephyr, the application heap default for a C or C++ image with the parameter services and no lifecycle drops from 192 KiB to 112 KiB. Rust images and lifecycle images keep 192 KiB.
