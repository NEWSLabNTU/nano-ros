The C/C++ metadata probe's parameter store now holds 1,024 parameters, so a
component that declares more than the 32-slot build default (an Autoware
controller declares about 150) is probed. Before, it either ran on compiled
defaults or stopped at the full store and went unprobed. Sidecars written under
the old size are probed again on the next `nros configure`.

The C/C++ metadata probe constructs each component with its launch values. A component that declares a parameter without a default and takes it from the launch file (an `rclcpp` `declare_parameter<T>(name)`, a C `rclc_add_parameter`) used to read `T()` under the probe, so its probe failed or recorded the wrong entities. `nros sync` now seeds the probe from the models it resolved, through the same projection the image's entry bakes, and records the seeds in the sidecar's `probe` object. Instances that disagree on a value are probed on the declaration defaults, with a note, or refused naming each instance's value when that probe fails. An edited launch value re-probes the component.
