`rclcpp::ParameterEventHandler` on hosted C++ builds: react to another node's
parameter changes with `add_parameter_callback(name, cb, node_name)` (the
callback receives a new hosted `rclcpp::Parameter`) or to every event with
`add_parameter_event_callback(cb)` (decoded into the image's generated
`rcl_interfaces::msg::ParameterEvent`). It is one `/parameter_events`
subscription per handler, counted like any other subscription. Handles
unregister when dropped. A freestanding build refuses the handler at compile
time.
