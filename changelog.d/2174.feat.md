A server contract stating `stale_after:` on a backend that delivers no request source timestamp is now a build-time warning. Each RMW backend states this in its `nros-rmw.toml` as `[rmw.facts] request_source_timestamp`: XRCE-DDS states `false`, zenoh and Cyclone DDS `true`. The codegen-system and C/C++ entry roads warn, naming the server, when a server the image runs declares `stale_after` on a backend that states `false`. A backend that does not state the fact gets no warning.
