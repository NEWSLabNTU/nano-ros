`nros image check --no-alloc` reads a built image and reports every allocation symbol it links, by family: the C heap, the Rust allocator, C++ `operator new` and an RTOS heap. It exits 1 on a finding and 2 when it cannot check, so CI can hold an image to it. `--tier unified` reads the build's objects instead, and allows allocation only through the platform's allocator. `--elf` and `--objects` name the files directly, and `--json` prints `nros.image.check.v1`.
