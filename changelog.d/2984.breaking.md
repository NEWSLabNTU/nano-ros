`nros::census_hooks::on_timer_create`, `on_guard_condition_create` and `on_device_create` are removed. Nothing replaces them, and there is nothing to call: the census now counts a timer, guard condition or device when the executor registers it, whatever route registered it. Code that called one of them (the module is `#[doc(hidden)]` and was meant only for nano-ros's own language layers) should delete the call; keeping it would no longer compile, which is deliberate, because it would count the slot twice.
