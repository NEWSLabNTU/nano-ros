`nros run` on a Zephyr board now starts a zenoh router for the image, or reuses one already running. It takes the router address from the Zephyr configuration the image was built with (`CONFIG_NROS_ZENOH_LOCATOR`, or the XRCE agent address and port), unless the image states its own `locator`. On mps2-an385-zephyr the image dials `tcp/10.0.2.2:7447`, so the mps2-an385 Zephyr starter no longer asks you to start `rmw_zenohd` by hand.
