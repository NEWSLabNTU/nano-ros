A board variant `s32z270-freertos-rtd` builds the S32Z270 RTU on NXP's GCC/ARM_CR52_GIC FreeRTOS port from a provisioned NXP kernel (`NXP_FREERTOS_S32ZE_DIR`) and RTD (`S32_RTD_PATH`), named as license-gated packages, so a consumer names the board instead of setting `FREERTOS_DIR` / `FREERTOS_PORT`. On that port nano-ros now creates its own tasks with `xTaskCreateFpu` / `xTaskCreateStaticFpu`, which the port needs for a task's FP context. The NETC network glue is not part of it yet.
