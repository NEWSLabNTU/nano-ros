The C++ node types are MERGED: `rclcpp::Node` and `nros::Node` are one class (`std::is_same` is asserted), carrying both the freestanding out-ref `create_*` family and upstream's `shared_ptr`-returning one as overloads — a ported `create_publisher<M>("chatter", 10)` compiles hosted and FAILS TO COMPILE on a freestanding target with a diagnostic naming the out-ref overload, rather than silently gaining a heap allocation per publisher. Hosted-only state lives behind one unconditional pointer allocated lazily, so `sizeof` is 200 bytes with and without `-DNROS_CPP_STD` (it was 192 and 3752 for the two separate types), and a node driven through the out-ref family never calls `operator new`. `Node::get_logger()` now returns a logger named for the node instead of the `"nros.compat"` sentinel, `Node(name)` / `init()` / `ok()` replace upstream's throwing constructor, `nros::bind_timer` is retired in favour of `node.create_wall_timer<C, &C::method>(out, ms, self)`, the `rclcpp::TimerBase` HIERARCHY is deleted in favour of the flat `rclcpp::Timer` (the name itself survives one release as a deprecated alias whose diagnostic carries the rename), `rclcpp::create_timer(node, clock, period, cb)` arrives for clock-driven timers, and `nros::Result` / `nros::Expected<T>` carry `[[nodiscard]]`
