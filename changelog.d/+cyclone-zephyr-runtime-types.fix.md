A Zephyr image on `rmw = "cyclonedds"` that declares `param_services` now creates its parameter services, so `ros2 param` reaches the node. Before, the Zephyr road linked none of the runtime's own interface types into Cyclone DDS, and the image booted logging `Transport(Unsupported)`. `nros build` now refuses an image whose enabled features need a runtime interface package that is missing, and on the cargo road a type that does not fit Cyclone's descriptor table fails its entity's creation, naming the type, instead of being dropped silently. Each type now takes one row of that table, so the table sized from an image's type count holds them all. ([Zephyr road](https://github.com/NEWSLabNTU/nano-ros/pull/4223), [one row per type](https://github.com/NEWSLabNTU/nano-ros/pull/4278))
