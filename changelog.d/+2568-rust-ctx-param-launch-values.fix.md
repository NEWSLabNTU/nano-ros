A Rust node in a C++ entry (a mixed C++ and Rust image) now reads its launch `<param>` values with `ctx.param(name)`, for both inline `<param>` and `<param from="...yaml"/>`. The Rust component install seam carried no params, so every read returned `None` and the node used its default. The seam now takes the node's params as a flat C-string array; the generated C++ entry passes them. (issue 2568)
