A PX4 uORB bridge image built for Jazzy now reaches a Jazzy subscriber. Two faults combined (issue 1893):

- The selected ROS edition now reaches the zenoh backend on the C/C++ road and through every embedded board crate. Before, it stopped short, so such an image published on Humble's `TypeHashNotSupported` key while advertising a RIHS01 hash. A backend now declares its edition feature in `nros-rmw.toml` (`[rmw.link] edition_feature`).
- The RIHS01 type hash of a `.msg` `char` field now matches rosidl's. rosidl hashes `char` as `uint8`; nano-ros hashed it as REP-2011's `CHAR`, so any message with a `char` field, such as PX4's `DebugKeyValue`, keyed on a hash no ROS 2 peer computes.
