On the CMake and west roads, a knob read at configure time now sees the image's `[image.<id>.knobs]` row, after a `-D` and the environment. `[image.<id>.knobs.freertos] app_stack_kb = 20` now sets a FreeRTOS C image's application stack (a bad value is refused, naming `app_stack_kb`), and the Cyclone DDS descriptor-table cap is read the same way. Before, only a `-D` reached them. ([details](https://github.com/NEWSLabNTU/nano-ros/pull/4256))
