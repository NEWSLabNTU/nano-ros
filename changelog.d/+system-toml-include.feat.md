A `system.toml` can now share fragments with `include = ["<path>", …]`, paths relative to the including file. Tables merge by key; a value stated in two files, an include cycle and a diamond are refused, naming the files; arrays of tables concatenate, includes first; and a fragment may not set `[system] name`, `[sources]` or `[tools]`. `nros`, the CMake road, colcon and the Python tools all read the expansion, and editing a fragment rebuilds what it affects. See the `system.toml` reference. ([expander](https://github.com/NEWSLabNTU/nano-ros/pull/4271), [Python reader](https://github.com/NEWSLabNTU/nano-ros/pull/4279), [CMake and colcon](https://github.com/NEWSLabNTU/nano-ros/pull/4294))
