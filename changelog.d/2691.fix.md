On FreeRTOS, the C library's wall clock now agrees with nano-ros's. `gettimeofday`, `time()`, `clock_gettime(CLOCK_REALTIME)` and, in a ported C++ program, `std::chrono::system_clock::now()` answer from the image's wall-clock source; with no source they read 0 (the epoch) instead of the time since boot posing as the time of day. `clock_gettime(CLOCK_MONOTONIC)` and `std::chrono::steady_clock::now()` read the monotonic clock, so they keep advancing and never step when a wall-clock source arrives. Any other `clock_gettime` clock is refused with `EINVAL`.
