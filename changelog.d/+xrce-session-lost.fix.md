An XRCE node now notices when its Agent restarts. A restarted Agent no longer holds the node's session; the backend asks it after a second of silence (`XRCE_SESSION_PROBE_MS`, 0 turns it off) and, on the Agent's "no session" answer, every drive, publish and ping returns the new `NROS_RMW_RET_SESSION_LOST` (Rust `TransportError::SessionLost`) and `Executor::session_lost()` turns true. Drop the executor and open it again to reconnect; `Executor::open` now gives its default backing back when the executor is dropped, so the re-open allocates nothing new. A publish refused because the Agent stopped acknowledging returns `WouldBlock` instead of `MessageTooLarge`, and `ping` answers `Timeout` only when nothing answered.
