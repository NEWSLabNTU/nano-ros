`nros pin --rev <sha> [--git <url>]` pins one commit, and `nros pin --path <dir>` pins a nano-ros checkout, with the checks the toolchain launcher applies: a full 40-hex sha, and a checkout root recorded relative to the pin file. Each form replaces the one the file held. In CI, every `nros pin` that would write now refuses, as `nros build` already does; `--dry-run` still reports.
