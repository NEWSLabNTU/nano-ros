A parameter a Rust node declares through `Node::declare_parameter`, `Node::declare_parameter_with_descriptor`, the typed parameter builder, or the deprecated `Executor::declare_parameter*` methods now reaches the parameter census. Before, a contract `params:` list that left one of them out sized the parameter store short and the build reported nothing; the `param-missing-in-contract` check now catches it. ([details](https://github.com/NEWSLabNTU/nano-ros/pull/4173))
