The direct-mode `config.toml` a hand-written `no_std` app bakes with `Config::from_toml` now uses the RFC-0109 D4 board network file shape: `[eth0]` with `network`, `host` or `address`, and `mac`, `[network.<name>]` for a network other than `qemu`, and `[node] locator` / `domain_id`. RFC-0004's `[[transport]]` panics at boot naming the new spelling, and `BaseConfig::apply_toml_field` is replaced by `parse_direct_toml` + `BaseConfig::apply_direct`. (#2047)
