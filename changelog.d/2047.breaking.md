The direct-mode `config.toml` a hand-written `no_std` app bakes with `Config::from_toml` now uses the board network file shape: `[eth0]` with `network`, `host` or `address`, and `mac`, `[network.<name>]` for a network other than `qemu`, and `[node] locator` / `domain_id`. The old `[[transport]]` table panics at boot naming the new spelling, and `BaseConfig::apply_toml_field` is replaced by `parse_direct_toml` + `BaseConfig::apply_direct`.
