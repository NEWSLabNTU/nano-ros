An idle Cortex-M image under the SDK's QEMU no longer costs a host core. QEMU 11's Cortex-M `WFE` support left an event pending after every interrupt, so `WFI` never halted the emulated CPU; the SDK's `qemu 11.0.0-nros8` carries the upstream fix. An idle mps2-an385 listener's QEMU process drops from 120 % to 0 % host CPU. Run `nros setup --tool qemu` to pick it up (issue 2209).
