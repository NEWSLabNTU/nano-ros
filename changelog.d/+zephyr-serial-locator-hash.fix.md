A Zephyr image whose zenoh locator is a serial one (`serial/<dev>#baudrate=<n>`) bakes its locator again. Since the locator became a backend-mapped role (issue 1299), `nros_rmw_zenoh.cmake` passed it as a compile definition, and CMake drops any definition containing `#` with only a configure warning, so the image fell to the empty locator and `nros_cpp_init` failed with Transport ConnectionFailed. The `#` now travels as the octal escape `\043` (issue 1955).
