New crate `nros-device`: device ports from Rust. A board implements `WorkerPort` (a job goes in, a result comes back, as for an accelerator) or `SourcePort` (data on the device's own clock, as for a camera), keeps the port in a `PortCell`, and exports a typed `WorkerHandle` or `SourceHandle` static. The same port can be exported to C and C++ nodes as a `WorkerPortOps` or `SourcePortOps` table, and a port written in C is named from Rust with `WorkerHandle::from_c`. A node opens a `Worker` and registers a `Stage` that submits jobs and receives each result as an executor callback, with the input's capture time (monotonic, plus the wall clock at the same instant) carried to the result; a `Source` delivers each item the device produces. A device has one owner, and a table of another ABI version is refused when it is opened. `nros_device::mock` has a worker and a source that need no hardware, and `nros_device::conformance` checks the rules every port keeps against any handle.
