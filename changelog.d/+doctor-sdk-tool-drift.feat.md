`nros doctor` now compares the SDK store with every pinned tool: a tool whose installed version is behind its pin, or a required tool that is missing, gets a `[WARN]` line naming `nros setup --tool <name>`. Superseded versions on disk and store directories no pin names are listed for information; nothing is deleted. `nros doctor --board <b>` also treats that board's packages as required. ([details](https://github.com/NEWSLabNTU/nano-ros/pull/4272))
