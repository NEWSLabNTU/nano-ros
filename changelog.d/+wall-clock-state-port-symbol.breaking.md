A custom platform port must now define `nros_platform_wall_clock_state()` beside `nros_platform_time_now_ns()`, returning whether its wall clock is synced and which source answers it. There is no default, so a port without it fails to link, naming the symbol. A port with no real-time clock returns `{ false, NROS_WALL_CLOCK_SOURCE_PLATFORM, 0 }`. A Rust port implements `PlatformTime::wall_clock_state`.
