The stack-floor walk no longer changes with where the project is checked out. It used to count any word in the image that happened to equal a function's address as a pointer to that function, so the same code walked up to 2.6 KB differently from one directory to another. The stack-floor build now links with `--emit-relocs`, and a function counts only where the linker actually wrote its address. Tables a link writes without a relocation (Zephyr's `sw_isr_table`, a linker-script vector table) are still read word by word. An image linked without relocations is refused, with a message naming the flag.
