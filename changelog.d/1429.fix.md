A C or C++ workspace whose model describes no wiring builds again. The cmake entity-facts emitter composed `NROS_DECLARED_TL_PUBLISHERS=` with no value, which is a fourth answer on a carrier whose contract has three (absent, `refused`, a count), and the zpico build script panicked on it — taking every template a user copies out that builds a workspace with it. The cause is a cmake reading trap: `get_property()` leaves its output variable UNDEFINED when the property was never set, so `if(NOT _v STREQUAL "")` compares the variable's NAME against `""`, never matches, and the guard meant to skip an absent fact emits a valueless one instead. All three emitter sites now read through `_nros_entity_fact`, which always defines its output; every `NROS_DECLARED_*` reader is total on an empty value (absent, with a `cargo:warning`, because a build script does not own its environment and `0` keeps its own spelling); and `check-declared-fact-carriers` gains a fourth rule that refuses the idiom outright, on the fast lane.
