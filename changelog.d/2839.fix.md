A Zephyr image's `platform` wall-clock source no longer claims to answer: Zephyr has no wall clock, so a source list ending in `platform` now reaches `clock.epoch_failure`. With the default, `unstamped`, nothing changes except the boot line, which now reads "no wall-clock source answered (...); stamps are unset" instead of "wall clock from platform"; with `halt`, the image now stops at boot as asked.
