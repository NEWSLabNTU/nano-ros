`nros configure` no longer prints a CMake error ("BOARD is not being defined",
or "Could not find a package configuration file provided by Zephyr") the first
time it runs on a C or C++ Zephyr application. Its metadata probe is a host
build, which cannot configure a `CMakeLists.txt` that calls
`find_package(Zephyr)`; such a package is now skipped with that reason
instead of attempted (issue 2280).
