Actions interoperate with ROS 2 Iron and Jazzy from Rust, C and C++: each of an action's five endpoints (send_goal, cancel_goal, get_result, feedback, status) is now keyed on its own type hash, where every registration path used one hash for all five and a Jazzy peer matched none of them (issue 1913). C users who build an `rclc_action_type_t` by hand should pass `ROSIDL_GET_ACTION_TYPE_SUPPORT(pkg, action, Name)` instead, so the descriptor carries the endpoint hashes.
