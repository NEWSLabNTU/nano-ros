A released `nros` now provisions from the SDK index it ships with, the same one its library sources and every other command read. It used to fetch `main`'s index, so `nros setup` could install a different QEMU or zenoh-pico than the build then asked for, and rewrite a project's committed `nros-sdk.lock`. To provision from a mirror, set `NROS_INDEX_URL` (issues 2256, 2257, 2258).
