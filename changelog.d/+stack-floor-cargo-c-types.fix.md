The stack-floor check now types the C that a cargo build script compiles. Every such compile goes through `nros_cc_flags::compile_commands::compile`, which writes a `compile_commands.json` beside the objects it builds. Each command records its object's size and hash, and the walk reads a command only for the object this link used. zenoh-pico's calls through function pointers were previously bound to every function C can reach, which inflated the walk. realtime-c's FreeRTOS image now walks 76 KB instead of 92 KB.
