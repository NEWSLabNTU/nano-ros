A launch file that runs two nodes of the same C component now gets two instances. Before, both nodes shared one static state and `rcl_node_t`, so the second configure overwrote the first and one of them silently did nothing. Each instance now has its own slot, up to `RCLC_C_COMPONENT_MAX_INSTANCES` (default 2; define it higher on the component's compile). One instance more than that is refused at boot with an error naming the package.
