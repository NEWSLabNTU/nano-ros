Rust Zephyr images for Cortex-M build again on the Zephyr 4.4 line. zephyr-lang-rust passed the C compiler's builtin include directory to bindgen, so clang parsed GCC's `arm_acle.h` (which CMSIS_6 includes) and failed with `argument to '__builtin_arm_cdp' must be a constant integer`. The Zephyr patch set now keeps that directory out of bindgen's include path, so no `BINDGEN_EXTRA_CLANG_ARGS` workaround is needed. Re-run `nros setup board <board> --zephyr-workspace <ws>` (or `just zephyr setup`) to apply it to an existing workspace (issue 2203).
