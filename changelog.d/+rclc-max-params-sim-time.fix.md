A C parameter server no longer counts the runtime's own `use_sim_time` against its `max_params`. On a node built with parameter services and `sim_time` (including `node_interfaces = "stock"`), the runtime declares `use_sim_time` on every node, as rclcpp does. rclc never declares it, so a node whose `max_params` fit exactly its own parameters refused the last one. The placeholder counts only once the application declares `use_sim_time` itself.
