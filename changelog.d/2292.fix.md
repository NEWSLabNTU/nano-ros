`nros new board <name> --for-platform <p>` now writes the same board package
as `nros board new <name> --platform <p> --out-of-tree <dir>`, including the
`package.xml` that announces the board. Before, it wrote no `package.xml`, so
`nros board info` and every other board reader refused the board it had just
scaffolded. A Zephyr board is scaffolded with `nros board new`, which takes the
Zephyr board id (issue 2292).
