An image on a Zephyr board can now write `log.max_level` as a level name (`"info"`, `"WARN"`, ...) as the knob registry documents; the Zephyr road used to refuse it as "an int -- write a decimal number" while the cargo road accepted it. A name is carried as its number (0 trace .. 6 off) on every road, and `-DNROS_OVERRIDE_LOG_MAX_LEVEL=<name>` works the same way.
