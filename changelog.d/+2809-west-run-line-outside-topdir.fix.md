The run and flash lines `nros build` prints for a Zephyr image now work where they are printed. The bare `west build -d <dir> -t run` and `west flash -d <dir>` lines failed from the image's workspace with `unknown command "build"`, because those are commands of the Zephyr west workspace. `nros build` now prints `nros run <image>` or `nros flash <image>` first, then the west line with the `ZEPHYR_BASE=` the build found. When no Zephyr tree was found, a note says what the west line needs.
