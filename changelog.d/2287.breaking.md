A CMake workspace's build dir now names the bringup: `build/<platform>-<rmw>[-<board>][-cfg<hash>]-<bringup>/cmake`, for example `build/posix-zenoh-linux-demo_bringup/cmake/linux_entry` where it was `build/posix-zenoh-linux/cmake/linux_entry`. Two bringups for one board no longer take turns rewriting one tree, so switching between them stops rebuilding the Rust runtime. `nros build` and `nros run` find the new path themselves; a script that names the old one must be updated, and the old dir can be deleted.
