C++: `rclcpp::ParameterCallbackHandle` is now upstream's type, the handle `ParameterEventHandler::add_parameter_callback` returns, so `rclcpp::ParameterCallbackHandle::SharedPtr h = handler->add_parameter_callback(...)` compiles (hosted builds). The `uint16_t` token used by the freestanding `add_on_set_parameters_callback(f, ctx, out)` / `remove_on_set_parameters_callback(token)` form is renamed `rclcpp::OnSetParametersCallbackToken`. Code that spelled that token `rclcpp::ParameterCallbackHandle` must switch to the new name.
