The S32Z270 RTU0 Cortex-R52 Zephyr board (`s32z270-rtu0-zephyr`) now reads "Builds": a C++ Cyclone image for it links in CI, in a job that fetches `hal_nxp` for itself, so no Zephyr workspace pays for the module. A west fixture's board id now counts as build evidence for the board whose descriptor names it. `nros build` also finds an image's `boards/<board>/` fragments for a board id that carries a revision (`s32z2xxdc2@D/s32z270/rtu0` reads `boards/s32z2xxdc2_s32z270_rtu0/`).
