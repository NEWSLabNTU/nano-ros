`NROS_MAX_PARAM_DESCRIPTION_LEN` is now sized from the parameter descriptions your code actually sets: the metadata probe records the longest description and constraints text, and the parameter store reserves the longest description (at least 16 and at most 256 bytes) instead of a fixed 256 bytes per slot. When the probe did not watch every launched node, or the image has only a contract, the size stays at 256; a value you set yourself (environment, Kconfig or board) still wins. ([recording](https://github.com/NEWSLabNTU/nano-ros/pull/4184), [sizing](https://github.com/NEWSLabNTU/nano-ros/pull/4187))
