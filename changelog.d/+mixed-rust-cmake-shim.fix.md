In a bringup that mixes C or C++ nodes with Rust ones, `nros new … --to <bringup>` gives every Rust package of the bringup its CMake registration: a `CMakeLists.txt` calling `nano_ros_node_register(LANGUAGE RUST)`, and `build_type nros_cmake`. The mixed image builds through CMake and needs both. The "Mix languages" book page now states this, and the build's `no matching component` refusal names the fix.
