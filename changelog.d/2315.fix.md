`nros run` (with the default `--router auto`) now reuses a zenoh router already listening on the image's locator, such as one a book chapter told you to start, instead of refusing or starting a second one, and says which endpoint it reuses. It checks with a zenoh handshake, so a port held by anything else is still refused. A serial board's router connects to a router already on the host's port 7447.
