The action cores' methods left the Rust user API. Every method of `ActionServerCore`, `ActionClientCore`, `ActionServerRawHandle` and `ActionClientRawHandle` (62 in all, constructors included) now sits behind a sealed trait in `nros_node::executor::ffi` (`ActionServerCoreFfi`, `ActionClientCoreFfi`, `ActionServerRawHandleFfi`, `ActionClientRawHandleFfi`), which `nros` does not re-export. The types are still reachable as `nros::internals::*` for sizing and storage. A Rust action server or client uses the typed `ActionServer` / `ActionClient`; a shim that drives the untyped core imports the trait from `nros-node`. (phase-515 R9)
