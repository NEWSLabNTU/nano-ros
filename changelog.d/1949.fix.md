The board console sinks for the `log` crate (Linux, FreeRTOS, MPS2-AN385,
NuttX, ThreadX and ESP32-QEMU) now filter on `nros_log`'s threshold for each
record's logger, `Info` unless the application lowers it. They used to print
every `log::trace!` and `log::debug!` in every crate: a hosted image publishing
at 500 Hz wrote and flushed a stdout line per publish. Lowering the threshold
with `Logger::set_default_level` or a logger's own level now reaches these
sinks too, including ESP32-QEMU's, which had fixed `Info` as the ceiling
(issue 1949).
