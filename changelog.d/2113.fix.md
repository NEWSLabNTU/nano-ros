The Zephyr Cortex-A53 SMP core-pin cell (`sched_dims` `CorePinPlacement/zephyr/c`) now asks for `qemu-system-aarch64` with the `virt` machine before it boots, and names the missing emulator instead of failing with a bare ENOENT. The emulator is a new `[prereq.qemu-system-aarch64]` row in `nros-sdk-index.toml` (apt `qemu-system-arm`), which the generated runner image installs (issue 2113).
