`zephyr` is no longer a framework an image can name. `[image.<id>] framework = "zephyr"` is refused with a message saying the board decides it: a Zephyr board's descriptor (`entry_kind = "zephyr-staticlib"`) imposes the Zephyr entry shape, and every Zephyr image still gets it with no `framework` line. The framework vocabulary is now `owned-spin`, `rtic` and `px4`. One resolver, `nros_orchestration_ir::image_framework`, answers "which framework" for `nros::main!`, `nros build` and the Rust entry pack, from the image's `framework` and the board's `frameworks` list; `framework_for_board_key` is gone. `board = "rtic-mps2-an385"` still builds the RTIC entry until that word retires.
