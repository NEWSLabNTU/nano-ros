A spawned level's worker frame is now measured on Zephyr, not estimated (issue 2065). `CONFIG_NROS_ZEPHYR_LEVEL_WORKER_FRAME` defaults to 13,312 B, the C runner's setup peak on the S32K344 safety island (12,464 B), instead of the 4,096 B estimate; `NROS_ZEPHYR_TIER_STACK_SIZE` is unchanged, so a level whose members state no stack keeps 16 KiB and only the per-callback default shrinks (to 3,072 B). The Rust pack derives Zephyr level stacks over the Rust runner's own frame, 51,200 B (`level_worker_frame_bytes("zephyr", LevelRunner::Rust)`, measured on mps2/an385 under QEMU). `nros-mem-report.py`'s Zephyr default follows the Kconfig, and its selftest reads the Kconfig back.
