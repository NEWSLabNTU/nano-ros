The host board, lane, scope and `just` module are `linux`, and the old spellings are now refused instead of mapped: `nros setup native`, `nros setup posix`, `nros new --platform native|posix`, `board = "posix"`, `lane=native`, `just build|test|doctor|setup native` each stop with a message naming `linux`, and the old `native` module forwarder is gone (use `just linux …`). Release 0.5.0 documented `nros setup native` and `--platform native`; type `linux` instead. `posix` remains the platform's name (`nros-platform-posix`, `NROS_PLATFORM=posix`, `[tiers.*.posix]`).
