The `s32z270-rtu0-zephyr` board declares its NETC interface in `[board.net]`, so an S32Z image can name a board network file and Zephyr configures its address or DHCPv4 lease before the application starts. A board network file can also state `vlan = <tag>` on an interface whose board allows it (`vlan = true`; the S32Z270 RTU0 does): `nros build` renders `CONFIG_NET_VLAN` and `CONFIG_NROS_NET_VLAN_TAG`, and the nros Zephyr module tags the Ethernet interface and puts the address or lease on Zephyr's VLAN interface, waiting for it at boot as `NET_CONFIG_NEED_IPV4` does.
