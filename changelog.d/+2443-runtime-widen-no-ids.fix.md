Board crates, build helpers and examples no longer print internal design ids at run time or in a build: the FreeRTOS, Zephyr, NuttX, ThreadX and S32Z270 boards' sched-task, core-pin, heap and netif messages, the board `config.toml` refusals, the cross-compile skip warnings, the NuttX sizes-header and vector-table refusals, and the mps2-an385 C++ examples' build-script refusals. Several now say what to do: regenerate the entry with `nros build`, set `NROS_C_INCLUDE`, depend directly on nros-c and nros-cpp, or keep an interface's address keys in one section.
