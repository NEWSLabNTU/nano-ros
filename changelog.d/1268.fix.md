Parameter services on Cyclone are verified against a live ROS 2 peer, not only against our own tests. `ros2 service list`, `ros2 param list/get/set` were run against a two-node Cyclone image with `param_services`: all twelve `rcl_interfaces` services are on the wire (six per node), each node answers with its own value for a parameter name they share, and a write to one leaves the other alone. The two-node fixture gains the RMW feature axis it needed to be pointed at Cyclone at all — it was pinned to zenoh, the one backend on which a parameter service cannot fail on type grounds — and the run is now an interop cell (`native-params-per-node-rust-cyclone`) with a recorded verdict, so it stays checked.
