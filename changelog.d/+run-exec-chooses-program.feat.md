`nros run <image> --exec <name>` chooses which program to run when the image's entry package builds several, as `ros2 run <pkg> <exe>` does. Without the flag, the program the bringup's launch file names for that package is used, or the package's only program. With several programs and none named, `nros run` lists them and says how to choose, and `nros build` prints one run command per program.
