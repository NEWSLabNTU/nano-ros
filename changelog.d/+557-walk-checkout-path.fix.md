The stack-floor check measures the same stack depth for one commit wherever it is checked out. Before, the order it explored calls in moved with the checkout's path, enough to change the mps2 bare-metal talker's measured depth by 3 %. The four measured images are re-measured. The merge queue now re-measures the mps2 bare-metal talker on every merge, so a change that moves its stack depth fails the queue instead of waiting for the nightly check. A measured depth above the recorded one fails only when it exceeds the largest depth recorded for the image, because the compiled code itself differs slightly between checkouts.
