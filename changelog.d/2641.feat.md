A new `rclc_trace_marker(id, arg)`, with `rclcpp::trace_marker` and `nros::trace_marker::emit_app_marker`, emits an application event through the installed callback trace sink, on the same path and clock as the executor's callback events. Application ids are 1 to 15. An executor id (16 and up) or 0 is refused with an error and a log. On Zephyr the default sink puts the event in the CTF stream; on FreeRTOS, POSIX, NuttX and ThreadX it goes to a sink the application installs.
