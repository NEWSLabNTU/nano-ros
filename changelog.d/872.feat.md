The parameter store is sized from the launch contract's `params:` (phase-446 W4): the slot count and name length follow the declared parameters, a string / array / byte-array capacity is 0 unless a declared type needs it, and the build refuses, naming the parameter and the knob, when a declared type needs a capacity that no board, Kconfig or environment value states. Zephyr gains `CONFIG_NROS_MAX_PARAM_NAME_LEN`, `CONFIG_NROS_MAX_STRING_VALUE_LEN`, `CONFIG_NROS_MAX_ARRAY_LEN` and `CONFIG_NROS_MAX_BYTE_ARRAY_LEN`, and `CONFIG_NROS_MAX_PARAMETERS` now defaults to -1 (derive).
