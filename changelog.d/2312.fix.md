`nros setup board <zephyr-board>` (and `nros setup <zephyr-board>`) now installs the pinned nightly that the Zephyr C/C++ road builds `nros-c` with on an embedded triple, with `cargo`, `rust-src`, `rustfmt` and the board's target, and `nros build` / `nros run` refuse before cmake, naming `nros setup board`, when it is missing. The Zephyr and NuttX cmake files read that channel from `config/rust-toolchains.txt` instead of a literal, so a fresh host's first build no longer depends on rustup's auto-install.
