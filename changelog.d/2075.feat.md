Rust components: a declared timer can be started, restarted and stopped by its entity id. `CallbackCtx::reset_timer(EntityId)` / `cancel_timer(EntityId)` and their `TickCtx` twins are rclcpp's `TimerBase::reset()` / `cancel()`, so a timer declared with `autostart = false` can now be started from another callback. The request takes effect at the component's next tick, in the same spin. `EntityBounds` gains `timers`, the size of the id-to-handle table (16 bytes a row). `EntityBounds::exact(..)` sets it to 0, and `.with_timers(n)` raises it. An id with no controllable timer answers the new `NodeDeclError::UnknownTimer` (issue 2075).
