C++ subscription callbacks may take the message by smart pointer on hosted
builds (`-DNROS_CPP_STD`): `M::UniquePtr`, `M::SharedPtr`, `M::ConstSharedPtr`
and `std::shared_ptr<const M>`, by value or `const&`, including `std::bind`
over a member. Generated C++ messages, service requests/responses and action
goal/result/feedback types now carry rosidl's `SharedPtr` / `ConstSharedPtr` /
`UniquePtr` / `ConstUniquePtr` / `WeakPtr` / `ConstWeakPtr` aliases there. Each
delivery to a pointer-shaped callback is copied into a heap object the callback
owns and may keep; a `const M&` callback still allocates nothing. Freestanding
builds refuse the pointer shapes at compile time with a message naming
`const M&`. The stock jazzy `minimal_subscriber` lambda now ports with no edits.
