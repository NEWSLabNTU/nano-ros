The real-time promise (RFC-0113, now Stable) holds on every supported way to run nano-ros. Each tier parks on one wait object that fires only on an arrival for that tier or on its next deadline. Every backend reports arrivals as Notify or Waitable, a combination with neither is refused at open instead of polled, and the host-driven surface is gone. The promise is measured on Linux, Zephyr (mps2/an385) and PX4 SITL, and PX4 is a Tier 1 framework (phase-521, complete).
