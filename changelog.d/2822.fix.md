A C/C++ component that calls the platform CAN driver (`<nros/platform_can.h>`) now links in a census host build, a metadata probe and a host image with a CAN device. The CAN backend archive (`nros_can_census_mock`, `nros_can_socketcan`) was put on the link line before the component archives an entry reaches through their `<pkg>_<exec>_component` wrappers, so the link failed with `undefined reference to nros_platform_can_open`; it now goes on each archive's link interface, as the Zephyr kernel does (issue 2273).
