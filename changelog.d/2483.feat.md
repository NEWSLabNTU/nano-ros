A node declares `use_sim_time` as a stock ROS 2 node does. The new `sim_time` capability (in `[system] features`, and part of `node_interfaces = "stock"` with the parameter services and `/rosout`) builds the `/clock` time source into the image on every road: Rust, C and C++ (`nros-c` and `nros-cpp` gain a `sim-time` feature), CMake and Zephyr (`CONFIG_NROS_CAPABILITY_SIM_TIME`). Every node serving parameters then lists `use_sim_time` (bool, false), and `ros2 param set <node> use_sim_time true` is accepted and subscribes the executor to `/clock`. That subscription is reserved in the sized pools (a subscriber, a callback slot, an executor arena entry and a liveliness token, once per executor) whenever the capability is built in, so a switch at run time never finds the pools full. The sizing descriptor's `infra_families` gains the word `clock`.
