A C or C++ image with `param_services` (or `lifecycle`) on Cyclone DDS now creates its parameter services, `/parameter_events` and lifecycle services: the CMake build generates the `rcl_interfaces` / `lifecycle_msgs` descriptors the runtime's own entities need. Before, `rclc_parameter_server_init` returned `RCL_RET_ERROR` and the example exited 1 with no message. Every C/C++ call that creates an entity now logs which entity failed and why, and returns the closest error code instead of a bare `RCL_RET_ERROR` (issue 2304).
