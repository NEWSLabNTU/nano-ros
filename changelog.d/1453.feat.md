The merge queue now builds every copy-out template under `examples/templates/` from a copy of the tracked file set (`just check template-copy-out`, new `gate.yml` job `check-template-copy-out`, feeding the required `CI` on `merge_group` and runnable by `workflow_dispatch`), so a template a user copies can no longer land unbuildable on `main` unseen. The gate now checks its tools (in-tree `nros` CLI freshness, `nros-launch-resolve` presence and freshness) before building anything and names the remedy, instead of reporting a missing tool as "the copy does not build"; `check merge-group-gates` keeps the placement from being silently moved off the queue (issue 1453).
