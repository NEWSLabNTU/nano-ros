In a project that was a leaf and is now a workspace, the leftover leaf-era configure stamp and census no longer answer for the workspace. `nros locate configured --image <id>` now reads the workspace's stamp, so a just-configured image no longer reports stale, and the old leaf census no longer enters the workspace's inputs. The ignored file is named on stderr. ([details](https://github.com/NEWSLabNTU/nano-ros/pull/4282))
