A FreeRTOS image can opt in to `[image.<id>] stack_floor = "raise"`. When the walk measures a stack floor above the stack the image states, `nros build` then builds the image once more at that floor instead of failing. This works on both the cmake and cargo roads. The raise is derived again on every build, is never stored and never lowers a stack. The build prints the value it used. On the cargo road it also prints the `[image.<id>.knobs.freertos] app_stack_kb` line that makes the value permanent. The FreeRTOS cmake check now also keys by the `stack_floor_image` stamp that `nros new` writes.
