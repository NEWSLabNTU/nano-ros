Board facts can reach Zephyr images again. `nros_resolve_board_facts` looked the CLI up under one of its two cache names, cached every failure in the CMake cache permanently, and never passed `--nano-ros-path`, so every Zephyr configure reported "no nros CLI" and a build dir that once failed could never recover. It now asks the shared `nros_resolve_cli`, remembers a failure for one configure only, and names the checkout it belongs to.
