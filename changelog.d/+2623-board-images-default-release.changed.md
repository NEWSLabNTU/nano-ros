A Rust image on a board now builds optimized by default, as a C or C++ image already did. Before, a Rust image with no `profile` built cargo's unoptimized `dev` profile: the mps2-an385 FreeRTOS talker was 914,880 bytes of flash against 515,536 at `release`. The `release` profile now also uses fat LTO, as the C and C++ images do, which saves about 15 KB more. A host image keeps cargo's `dev`. To build a debug image on a board, run `nros build <image> -- --profile dev`, or set `profile = "dev"` on the image.
