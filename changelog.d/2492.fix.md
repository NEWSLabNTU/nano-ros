A hosted (Linux) image now keeps its zenoh pool-exhaustion diagnostics when a test or supervisor kills it. The zenoh shim's console lines flush as they are written instead of waiting in stdout's buffer. A plain-API `main` that calls `nros_board_linux::register_linked_rmw` now gets the default log sinks, so framework errors such as a refused liveliness token reach stderr instead of being held until exit (issue 2492).
