A ported Nav2 node builds and runs. Hosted C++ gains `Node::WeakPtr` / `lock()`, `Clock::SharedPtr`, `FixedSequence::resize`, `rclcpp::Context` (pre/on-shutdown hooks, `get_node_base_interface()->get_context()`), `rclcpp::spin(get_node_base_interface())`, `LifecyclePublisher::publish(std::unique_ptr)` and `get_subscription_count`, `{sec, nanosec}` message conversion from `rclcpp::Time` with `+`/`-` a `Duration`, and an ignorable `timer_->cancel()` / `reset()`. Generated messages have field-wise `operator==`. `rclcpp_lifecycle::LifecycleNode::shared_from_this()` returns its own type, and its lifecycle services are served under the node's name (they were `/node/...`). An ament package that depends on `rclcpp_lifecycle` gets `lifecycle` in its runtime. The C++ parameter calls publish their `/parameter_events` at once, so a burst of declares no longer drops events. A log message that overflows keeps what fits instead of only its first argument, and truncation no longer splits a UTF-8 character.
