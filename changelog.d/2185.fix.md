A Zephyr west workspace you made yourself now gets nano-ros's patch set from
`nros setup board zephyr --zephyr-workspace <ws>` (the generic `zephyr` board
refused it before), and a Rust image's configure refuses a workspace without
the patch that carries nano-ros's board settings to its cargo command, naming
that command. The Zephyr chapters run the step after `west update`, and the
4.4 patch set now carries that patch too.
