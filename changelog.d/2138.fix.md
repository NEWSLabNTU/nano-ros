The fixture staleness probe no longer reads a C/C++ zenoh image as STALE after an edit to a build-script dependency such as `nros-zpico-build` that changes nothing the build script emits. When `zpico-sys`'s build script re-ran after the edit and the binary links a byte-identical rebuild of its staticlib, the probe counts those inputs as answered by the relink, the same rule issue 1710 applied to cargo's own dep-info (issue 2138).
