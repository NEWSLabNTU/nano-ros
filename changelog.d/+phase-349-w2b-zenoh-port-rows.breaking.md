A platform's `nros-platform.toml` no longer describes how zenoh-pico builds on it. Those keys moved, unchanged, to a `[port.<platform>]` row in the zenoh backend's `packages/rmw/zenoh/nros-rmw-zenoh/nros-rmw.toml`. The platform file keeps what any vendored C build needs as top-level keys: `arch_profiles` (formerly `arch` inside `[build.zenoh]`), `compile` and `required_env`. A platform file that still has a `[build.zenoh]` table is now a load error that names the key, so an out-of-tree platform descriptor must move its block the same way (phase-349 W2b).
