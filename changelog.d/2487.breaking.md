`IntegrityStatus::is_valid()` is now true only when a CRC was checked and matched. A sample with no CRC is still delivered, but `is_valid()` returns false for it. On zenoh this changes interop: a safety subscriber now reports samples from a publisher built without safety, including any stock ROS 2 node, as not valid. Before, they read as valid. To accept unprotected publishers, read `crc_valid` and decide in the application. The C and C++ APIs already reported `crc_valid` this way.
