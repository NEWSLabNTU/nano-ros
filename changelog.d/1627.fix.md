A `west-configure` fixture that failed CMake's generate step was counted as built, because its declared `output` (`CMakeCache.txt`, or the module's own `nros-system/system_config.h`) is written before generate runs — four FATAL configure errors once reported as `1 of 5 FAILED`. The three rows now declare `build.ninja`, which only a successful generate writes, so `west-fixtures.sh` keeps its one rule ("the row declares what must exist") with a premise that holds; `fixtures-manifest.py validate-compile-checks` refuses any other output for that builder. `require_west_fixture` now also requires the build's `.compile-ok` stamp, so a test no longer passes over a configure the lane counted FAILED by reading a file the failed configure left behind.
