`nros setup` run outside a checkout reads the index that shipped with the CLI (the release's `share/nano-ros`, or an in-tree `nros`'s own checkout) before the fetched copy in the store, so a stale cache no longer answers "unknown board" for a board the current index has. A cache older than the binary is still used as a fallback, with a note naming `NROS_INDEX_REFRESH=1` (phase-548 W5).
