An image names its CAN frame device in one place per board stack: `[image.<id>.can] device = "vcan0"` in `system.toml` on a host board (or `driver = "mock"` on a board that runs as a host process), and a `[canN]` table (`bitrate`, `dbitrate`, `frames = true` to pick one of several) in the board network file on a `"board"`-stack board. `nros configure` refuses each fact stated in the wrong home, naming the right one, and a device on a board whose `links` lack `can`. The resolved device rides `NROS_IMAGE_NET` as a `can` row.
