A node whose code declares a parameter its launch contract's `params:` do not declare, or declares one with another type, now refuses the boot naming the node, the parameter and the contract (phase-446 W6). C++ `ComponentNode::declare_parameter` checks against a generated per-node table (`nros/declared_params.hpp`); a Rust `nros::main!` image hands the same table to the executor. Nodes without `params:` are not checked, and `use_sim_time`, `start_type_description_service` and `qos_overrides.*` are always allowed.
