The knob registry is now the configuration registry: besides build knobs it lists the `system.toml` statements and every environment variable a running image reads, with what the image does with each (respect, ignore or refuse). Every retired spelling records the road it was used on and, where a unit changed, the factor that converts an old value. `nros configure` writes the merged catalog to `build/nros/knobs/catalog.toml`. `NROS_ENTRY_SPIN_MS` is listed as a run-time variable only: `[image.<id>.knobs.entry] spin_ms` was never read by a build and is no longer a knob.
