A Zephyr C++ image built with newlib on a 64-bit Arm board (e.g. `fvp-aemv8r-smp`) can now call `fabsl` and `copysignl`, so code reaching Eigen's long-double `abs` builds without a consumer `-Dfabsl` define. newlib declares no long-double math there; nano-ros's `<cmath>` supplies the two exact sign-bit functions and leaves the rest undeclared.
