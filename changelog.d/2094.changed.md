NuttX zenoh images now use the same 100 ms socket receive timeout as every other port, instead of 5000 ms. zenoh-pico's executor checks its timers only between receives, so NuttX keep-alives and query timeouts now run at most ~200 ms late instead of ~10 s, and the NuttX e2e cells run 2–16x faster (a C++ service round trip went from 19.4 s to 1.2 s).
