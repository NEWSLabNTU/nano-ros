The old contract spellings that ros-launch-manifest renamed are now refused, each with an error that names the replacement: `functions:` (now `capabilities:`), a hazard's `enters:` (now `leaves:`), a manifest-level `paths:` (now `event_chains:`), `min_rate_hz`/`max_rate_hz`/`rate_hz` (now `min_rate`/`max_rate`/`rate` with a unit, `100Hz`), a contract's `supervision:` (now the target's platform file), `policy:` (now the checker's `--deny <rule>`), `integrity_levels:` (now `use:` of a profile), `max_transport` on an endpoint or a service (now a link), `observes:` as a string (now `{ input }`) and `early.drop` (now `early.decrease`). Run `play_launch migrate <contract> --write` to rewrite a contract. The system model is schema 6: `contracts.scope_paths` is `contracts.event_chains`; older models still load. (ros-launch-manifest v0.3.27, play_launch 0.36.0.)
