A FreeRTOS board package kept outside nano-ros now states only its facts: the family configuration directory is on the include path of every FreeRTOS C build, on the cargo and CMake roads, so a board's `FreeRTOSConfig.h`, `lwipopts.h` and `arch/cc.h` include the family's headers by name instead of copying them. The family headers are renamed to `nros_freertos_family_config.h`, `nros_freertos_family_lwipopts.h` and `nros_freertos_family_cc.h`; a board-less integration that included `packages/boards/nros-board-freertos/config/FreeRTOSConfig.h` (or `lwipopts.h`, `arch/cc.h`) by path includes the new name.
