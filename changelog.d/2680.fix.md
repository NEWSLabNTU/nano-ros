The C/C++ metadata probe now adds a node package's build-time workspace dependencies (`<depend>`, `<build_depend>`, `<build_export_depend>`, transitively; not interface packages, packages outside the workspace, or packages without a `CMakeLists.txt`) to its one project, before the node and each once. So a node that includes a header from a sibling workspace library probes without an `add_subdirectory` fallback in its own `CMakeLists.txt`. The probe's freshness key covers those dependencies' sources, a dependency cycle or a west-application dependency is refused naming it, and a dependency's configure error is reported against every component that needs it.
