The census of an owned C/C++ entry on a cross board now generates the workspace's own message packages. The census is a host build of the entry's package alone, and that build put nothing of the workspace on its interface search path, so an entry that `<depend>`s on a message package under the workspace's `src/` failed to compile (`fatal error: <pkg>/msg/<type>.hpp: No such file or directory`) and its census was refused, or skipped with a warning under `[census] on_missing = "warn"`. The census build now puts the workspace's `src/` first on `NROS_INTERFACE_SEARCH_PATH`, as the cross build's generated root does, and a gate (`just check owned-census-local-msgs`) takes the census of such an entry.
