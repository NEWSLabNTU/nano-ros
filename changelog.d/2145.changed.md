`Executor::spin_async` no longer busy-loops when idle on a backend that wakes on arrival: it registers the task's `Waker` with the executor's readiness path and returns `Pending` without waking itself. The new `Executor::spin_async_with_sleep(sleep)` takes the runtime's sleep (`tokio::time::sleep`, Embassy `Timer::after_micros`) and also sleeps until the executor's next deadline. Plain `spin_async()` has no timer, so it still self-wakes while any deadline is pending (on zenoh, always); poll-only backends (XRCE, smoltcp) self-wake as before (issue 2145).
