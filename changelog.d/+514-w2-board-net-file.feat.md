An image's network address lives in its board network file, named by `os_config` in `[image.<id>]` (RFC-0109 D4): one table per interface (`[eth0] network = "qemu"`, `host = 10`), beside `system.toml`. Both build roads read it, and an interface stated both inline (`net = { … }`) and in a file is refused. Every in-tree image (78) moved to the file form, and resolves to the same address, MAC and locator as before.
