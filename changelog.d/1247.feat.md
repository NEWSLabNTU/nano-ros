An RFC-0047 subnode package now builds for a freestanding target: `workspace-cpp-freertos-realtime-subnode-portable` links `subnode_pkg::SubNode` — an `rclcpp::Node` derivation with two callback groups on two tiers — for FreeRTOS on mps2-an385 (`thumbv7m-none-eabi`). The component source is unchanged; the port is a `[tiers.*.freertos]` priority pair and an `[image.freertos]` block in `deploy_bringup/system.toml`, which is the RFC-0047 portability claim measured against a cross toolchain. `subnode_freestanding_link.rs` reads the linked image and asserts the derived node is instantiated, both group-bound timer trampolines are present, and the firmware carries zero vtable/typeinfo symbols.
