FreeRTOS images now resolve the wall clock after the network is up, so a board clock that needs the network (an SNTP exchange, for one) can answer, and the line reporting which clock answered is printed. Before, the first wall-clock read resolved it, and on an image built with Cyclone DDS that read ran before network start-up, so such a board clock never answered. Wall-clock reads before that point read 0.
