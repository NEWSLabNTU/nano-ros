`nros run` and `nros flash` on a Zephyr board no longer need `ZEPHYR_BASE` in the shell, or a project inside the west workspace. The run plan now carries the Zephyr tree the image was built against, read from its build's CMake cache, and the `west` and `fvp` runners point `west` at that tree. Before, the run failed with `west: unknown command "build"`.
