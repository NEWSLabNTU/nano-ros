A FreeRTOS zenoh build no longer panics in `zpico-sys`'s build script reading `nros_zp_condvar_slice.h` from the SDK store. The header is nano-ros's own source and is now located under `zpico-sys`, not beside wherever zenoh-pico was resolved from — which, whenever the store held the pinned zenoh-pico, was `~/.nros/sources/zenoh-pico`.
