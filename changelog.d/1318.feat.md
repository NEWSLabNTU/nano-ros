`nros::Time::to_ros_msg()` converts a `Time` into any generated message shaped `{int32 sec, uint32 nanosec}` — the Rust counterpart of the C++ `Time::to_msg` template. Codegen emits the `SecNanosecMsg` impl by field shape, so `builtin_interfaces/msg/Duration` binds too; the conversion is infallible and returns the message, not a `Result`.
