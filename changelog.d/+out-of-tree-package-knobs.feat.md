A board, platform or RMW package kept outside nano-ros can declare its own knobs and run-time variables in an `nros-knobs.toml` beside its descriptor, and an image states one exactly like a built-in knob, as `[image.<id>.knobs.<owner>] <name>`. The package's build script reads the value with `nros_knob_build::emit` (from the new `nros-knob-build` crate), which writes the package's rows as typed Rust items; on Zephyr the knob also lands in the image's `.config`. `nros knob list` and `nros knob show` include these knobs, with the package that declares each one and where it was found, and `nros knob render --kconfig <package>` writes a Kconfig for a package that is its own Zephyr module. An image that states a knob of a package it does not link is refused, and the message names the package that owns the knob.
