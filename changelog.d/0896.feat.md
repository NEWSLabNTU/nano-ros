Generated C++ message headers now state the type's DERIVED serialized-size bound as `Msg::TX_MAX_SERIALIZED_SIZE` / `Msg::RX_MAX_SERIALIZED_SIZE` — the same `nros_serdes::size::max_serialized_size` number the C header and the Rust `MAX_SERIALIZED_SIZE_XCDR*` const carry — and `nros::bind_subscription` sizes its subscription's receive buffer from it instead of the older `SERIALIZED_SIZE_MAX` estimate; a type with no bound poisons the constant with a `static_assert` naming the type and the member that costs it the bound, and `nros::bind_subscription_sized` is the escape hatch
