Every C or C++ workspace image now has a CMake configure and Rust runtime of its own, built and sized for exactly what that image declares, so its build dir names the image too: `build/<platform>-<rmw>[-<board>][-cfg<hash>]-<bringup>-<image>/cmake`, for example `build/posix-zenoh-linux-demo_bringup-linux/cmake/linux_entry` where it was `build/posix-zenoh-linux-demo_bringup/cmake/linux_entry`. An image's own `features` and `node_interfaces` now reach its build, and an image no longer pays RAM or flash for what another image on the same board declares. Each image costs one more configure and runtime build. `nros build` and `nros run` find the new path themselves and remove the old directory; a script that names the old path must be updated.
