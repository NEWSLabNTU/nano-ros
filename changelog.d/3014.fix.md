`nros run` of a Zephyr image on the qemu-cortex-a53 board now boots without root: the board puts its network card on QEMU's user network (the host at 10.0.2.2), where its run line used to ask for a TAP device that only root can open. An image that really wants a TAP opts in with an `os_config` fragment setting `CONFIG_NET_QEMU_ETHERNET=y`.
