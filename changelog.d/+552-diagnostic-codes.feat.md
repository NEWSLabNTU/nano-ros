Refusals now carry a diagnostic code. A refusal prints as `error[NROS-0001]: …`, then a `help:` line with the fix and an `explain: nros explain NROS-0001` line; `nros explain NROS-NNNN` prints what happened and how to fix it, offline, from text built into the `nros` binary (`nros explain <plan>` still renders a plan). The first codes cover the refusals of a first build: ROS 2 not sourced (NROS-0001), a misspelt board (NROS-0002), a workspace with no image (NROS-0003), an image with no board (NROS-0004) and an out-of-tree platform that reaches no built-in family (NROS-0005). The book lists every code under Reference, Diagnostic codes.
