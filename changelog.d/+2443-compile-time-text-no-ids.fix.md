Compile errors, warnings and deprecation notes no longer cite internal design ids: the C/C++ `#error` refusals for zero array sizes, XRCE buffer and fragment limits, FreeRTOS static allocation and time slicing, NuttX priority inheritance, Zephyr receive timeouts and Cyclone poll entries; the renamed-API deprecations in C, C++ and Rust; the executor's compile-time size checks; and the `nros::main!` refusals.
