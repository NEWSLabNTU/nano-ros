A project-local QEMU (`build/qemu`) is used only while it holds the version `nros-sdk-index.toml` pins. A stale or hand-built one is refused, naming what it holds and the remedy (`just qemu setup-qemu`), instead of silently running every QEMU test on an emulator nobody chose. `just qemu setup-qemu` now replaces such a prefix, and `just check tier-preconditions` reports it before a run.
