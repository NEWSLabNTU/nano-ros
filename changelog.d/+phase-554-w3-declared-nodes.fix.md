An image now announces only the nodes it declares. An entity created on the executor rather than on a node (a timer's publisher, an executor-level service) is announced under the image's primary node, its first declared node, instead of under a separate node named after the executor session. The zenoh backend also announces each node with its first entity rather than at session open, as Cyclone already did. So `ros2 node list` against such an image no longer shows the extra executor-named node, and its entities appear under the primary node. In C, an executor with a node bound by `rclc_executor_node_init` refuses an entity created on a node that was not bound, and the error says to bind it.
