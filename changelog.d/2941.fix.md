Seven Zephyr `native_sim` example images stated a QEMU user-mode router address (`tcp/10.0.2.2:<port>`), which a `native_sim` image cannot reach: it runs as a host process and finds the router at `127.0.0.1`. They now state `tcp/127.0.0.1:<port>`, and the build checks refuse a QEMU user-mode address on a `native_sim` image.
