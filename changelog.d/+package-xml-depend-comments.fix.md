`nros configure` no longer reads a dependency out of a `package.xml` comment. The `<depend>` scanner matched tag text inside `<!-- ... -->`, so a comment such as "linked via CMake rather than declared as `<depend>` rows here." declared a package named `rows here.   -->`, which the configure then refused as a `<depend>` name that resolves to nothing. Comments are now removed before the scan, so a commented-out dependency declares nothing either.
