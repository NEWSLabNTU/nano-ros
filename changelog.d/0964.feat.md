Every RECEIVE buffer in the C++ API now sizes itself from the subscribed type's DERIVED bound where the type has one, via `nros::rx_buffer_capacity<M>` — `Subscription::try_recv` / `try_recv_validated`, `Service::try_recv_request`, `Client::call` / `call_polling`, `Future<T>` / `Stream<T>`, the action client's result and feedback, the polling tiers' result / feedback / goal, and `TickCtx::call`'s reply. Each grows a `_sized<N>` twin that takes the capacity explicitly, mirroring `bind_subscription_sized`, and a type with NO derived bound keeps the older `SERIALIZED_SIZE_MAX` estimate rather than becoming a compile error
