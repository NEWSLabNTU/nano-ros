A multi-package ROS 2 workspace configures in one CMake run. A sibling's `find_package(<pkg>)` finds the library package configured earlier (as `<pkg>::<pkg>`, with its CONFIG_EXTRAS run), not the installed upstream copy. `find_package` of an installed C++ library nano-ros does not ship is refused, naming the package. `rclcpp_lifecycle`, `rclcpp_action`, `rcl_interfaces`, `ament_cmake_python` and `rcutils` resolve, and message packages set `<pkg>_TARGETS`. A message that nests `std_msgs/Empty` now generates compilable C++ FFI glue. `rclcpp::Time` converts from a message stamp, and `<rclcpp/logger.hpp>` and `<rclcpp/parameter_service.hpp>` exist.
