The zenoh lease-task knobs are retired, because zenoh-pico 1.10 runs the lease and keep-alive on its executor (read) task (RFC-0110 D2). Each is now refused rather than ignored: `NROS_ZENOH_LEASE_PRIORITY` / `ZPICO_LEASE_TASK_PRIORITY` (environment, `[image.<id>] env`), `[image.<id>.knobs.zenoh] lease_priority`, `CONFIG_NROS_ZENOH_LEASE_PRIORITY` (now an undefined Kconfig symbol), `[node.rt] zenoh_lease_priority` / `zenoh_lease_stack_bytes`, and `nros_app_config_t.scheduling.keepalive_priority` / `keepalive_stack_bytes`. `zpico_set_task_config` takes two arguments, the executor task's priority and stack. Set the read-task knobs instead; the book's retired-names page lists each one.
