Network timers, connect waits and deadline QoS now run on the monotonic clock. On FreeRTOS and ThreadX, which have no wall clock, they read a clock that never moved; on a Linux host, setting the system clock moved every pending deadline with it. The bare-metal mps2-an385 and stm32f4 ports no longer report time since boot as the time of day: with no real-time clock, their wall clock reads zero, so a message stamp says "unset" instead of a plausible wrong date.
