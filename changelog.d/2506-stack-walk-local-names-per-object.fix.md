The stack-floor walk no longer merges two modules' machine-outlined code. At opt-level `s`/`z` LLVM's outliner numbers its `OUTLINED_FUNCTION_<n>` bodies from 0 in every module, and the walk keyed them by name, so a root in one module read the callees of another's body: an mps2-an385 bare-metal talker built at `z` walked 199,968 B, and walks 92,032 B now, against a measured peak of at most 28,672 B. Images built without the outliner walk exactly as before.
