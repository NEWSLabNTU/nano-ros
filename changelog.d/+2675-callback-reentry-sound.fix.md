A C or C++ callback that calls back into the executor dispatching it (cancelling or resetting its own timer, releasing an entity, a graph query) no longer creates an aliased `&mut Executor`. The C and C++ spin entries run the pass through a raw pointer, and the pass derives its references again after every callback. Rust callers get `Executor::spin_once_raw` and `Executor::spin_some_raw` for the same purpose; `spin_once` and `spin_some` are unchanged.
