Launch parameters for every node of a multi-node entry are seeded on that node, not all on the executor's primary node, so two nodes that set the same parameter name each read their own value. `nros_cpp_declare_param` takes the node's index as a new second argument (C ABI change), the generated C and C++ entries pass it, and the shim refuses an index that is not the next node the executor builds. `nros::main!` seeds each node's values as that node is built, and `RuntimeCtx::apply_param_services` no longer takes a parameter list.
