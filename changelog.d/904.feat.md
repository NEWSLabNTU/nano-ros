A parameter description has its own capacity, `NROS_MAX_PARAM_DESCRIPTION_LEN` (default 256, the most `ros2 param describe` can carry; 0 = no descriptions; Zephyr `CONFIG_NROS_MAX_PARAM_DESCRIPTION_LEN`; board `[knobs.params] max_param_description_len`). It used to share the string-value capacity, which a contract-sized store derives to 0, so a scalar-only image lost every description. A description longer than the capacity is now truncated at a character boundary and logged once per parameter, naming the knob, instead of being dropped whole in silence, and the typed builder no longer refuses a declaration over it.
