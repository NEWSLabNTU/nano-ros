The C/C++ metadata probe now links the census's CAN mock into every probe executable, so a node that calls the platform CAN driver (`nros_platform_can_*`) is probed instead of failing with `undefined reference to nros_platform_can_close`. The mock is exported as `nros_link_can_census_mock(<target>)` from `cmake/NanoRosCanImage.cmake`; the census host build uses the same function.
