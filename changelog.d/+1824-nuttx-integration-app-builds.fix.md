The NuttX integration app (`CONFIG_NROS=y`, `integrations/nuttx/`) builds again. It asked the image crate for a `std` feature that nros-c and nros-cpp no longer have, so every build stopped in cargo; it now asks for `alloc` and `panic-platform`, the set the board's FFI crate uses. With `CONFIG_NROS_CPP_API=y` it also built a C image the link never used, and generating that image's crate left the C++ one outside its own cargo workspace, so the C++ configuration could not build at all; it now builds only the image that links.
