`ros2 param list` and `ros2 param dump` now see every parameter of a node.
`list_parameters` stopped at 64 names without saying so, and
`get_parameters` refused a request naming more than 64. Without a `params:`
declaration the parameter-service buffer now grows past the 4096-byte default
when the store's capacity needs it.

**Behaviour change:** `list_parameters` prefix and depth filters now follow
rclcpp exactly. A prefix matches itself or itself followed by `.` (`robot` no
longer selects `robotics`), and `depth` counts the separators AFTER the
prefix, exclusively (with prefix `robot`, depth 1 no longer returns
`robot.arm`; depth 2 does). With no prefix, depth N returns names with fewer
than N separators. Depth 0 is still recursive.
