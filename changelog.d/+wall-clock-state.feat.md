An application can now ask what its timestamps mean before it publishes: `rclc_wall_clock_state()` in C, `rclcpp::Clock::wall_clock_state()` in C++ and `nros_core::wall_clock_state()` in Rust say whether the wall clock is synced, which source answers it (the platform clock, SNTP, zenoh timestamps or the board), and how many times that source has changed since boot. While it is not synced, wall-clock stamps read zero, ROS's "unset" time.
