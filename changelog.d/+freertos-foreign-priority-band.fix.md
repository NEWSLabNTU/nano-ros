On FreeRTOS, the kernel's timer service task no longer shares a priority with an application level. It ran at 2, inside the band application levels are allocated from, so a level at 3 could starve the software timers. It now runs at 4, beside lwIP's network task, and the FreeRTOS priority plan states that band for tasks nano-ros does not create. A FreeRTOS image prints every task and its priority at boot.
