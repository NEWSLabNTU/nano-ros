A Rust component can now query the ROS graph, as C and C++ components already could. `TickCtx` (in `tick`) and `NodeContext` (in `register`) carry the fourteen queries the executor's `Node` has, under the same names and visitor signatures: `count_publishers`, `count_subscriptions`, `count_clients`, `count_services`, `get_node_names`, `get_node_names_with_enclaves`, `get_topic_names_and_types`, `get_service_names_and_types`, the four `get_*_names_and_types_by_node` forms, and `get_publishers_info_by_topic` / `get_subscriptions_info_by_topic`. An answer is what has been discovered so far, so one taken at registration is usually partial.
