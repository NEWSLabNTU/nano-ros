A scaffolded node builds quietly. `nros new` writes the bringup's `system.contract.yaml`, and the sizing inputs an image leaves to a default are reported once, as one `nros: sizing:` line from whatever writes the descriptor, instead of one `cargo:warning` per build script. `nros build --explain-sizing` (or `NROS_EXPLAIN_SIZING=1` on a configure) lists them in full. User-facing messages no longer cite internal issue numbers.
