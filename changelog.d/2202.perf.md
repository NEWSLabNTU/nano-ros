Zephyr images reserve far less kernel heap (`CONFIG_HEAP_MEM_POOL_SIZE`), which nano-ros itself no longer allocates from. The `mps2-an385-zephyr` board goes from 128 KiB to 8 KiB, `nucleo-f767zi-zephyr` from 16 KiB to 8 KiB, and the nano-ros module's default for a zenoh image from 64 KiB to 8 KiB. Measured peaks are 0 bytes on both boards and 232 bytes on native_sim, whose socket driver uses this heap. `cargo nano-ros` no longer writes a 64 KiB kernel heap into a new Zephyr project's `prj.conf`.
