Parameter services fit a 16 KiB main again, and cost less executor backing. Each node's set of six service servers is now built in place, in the executor's state, instead of being returned by value and moved in: on the S32K344 safety island the registration path's frames went from about 18 KiB to under 6 KiB, and main no longer overflows while the services register. The state carries one set per node the contract declares (it carried one per node-table slot, which includes a slot no set ever uses), 4,032 B less on that image. On a Zephyr image with the eDMA v3 driver (S32K3), a PRE_KERNEL_2 hook (`CONFIG_NROS_EDMA_WARM_RESET_QUIESCE`, default on) now disables and clears every eDMA channel a warm reset left running, so a system reset after a fatal halt no longer faults at the first interrupt unlock. ([#2387](https://github.com/NEWSLabNTU/nano-ros/issues/2387))
