New FreeRTOS integration shell, `integrations/freertos/NanoRosFreertos.cmake`, for a CMake project that already builds FreeRTOS with upstream FreeRTOS-Kernel's own CMake. Call `nros_freertos_integrate(NETSTACK <your lwIP target> …)` before `add_subdirectory(<nano-ros>)`. The shell consumes your `freertos_kernel`, `freertos_config` and network-stack targets and adds nano-ros on top, with no board file in the nano-ros tree. Configure fails, naming the problem, when a required target is missing, when no network stack provides the platform's `ip_stack` capability, when an exported include directory does not exist, or when there is no `FreeRTOSConfig.h`. nano-ros's own FreeRTOS boards now go through the same call (phase-349 W4).
