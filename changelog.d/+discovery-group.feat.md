`nros --help` lists the commands that show what nano-ros offers (boards, platforms, RMW backends, runners, knobs, interfaces, templates and diagnostic codes) in one group, "Find what nano-ros offers". Three spellings moved, and the old ones keep working: `nros setup --list` is now `nros toolchain list --available`, `nros explain <code>` is now `nros code show <code>`, and `nros config explain --platform <p>` is now `nros knob list --platform <p>`. `nros package list` is a second spelling of `nros list`. Diagnostics now end with `explain: nros code show <code>`.
