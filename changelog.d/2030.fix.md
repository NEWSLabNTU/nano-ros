The C action client's executor spin, and `rclc_action_client_poll`, now take cancel replies. Before, nothing on the C callback tier read them, so after four `rclc_action_cancel_goal` calls every request slot was held and the fifth was refused. The new `rclc_action_client_set_cancel_response_callback` delivers each reply's return code and the number of goals canceling. It is optional, because replies are taken whether or not one is set. `rcl_action_client_t` gained the field. (issue 2030)
