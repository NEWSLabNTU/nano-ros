A C/C++ Zephyr image built by `nros build` now has one entity-inventory composer. The resolve phase composes over the components the image's packages register (from `nros sync`'s metadata probe), by the same function `nros ws entity-inventory` runs, and the configure reads that answer instead of recomposing whenever its own inputs match. The configure-time producer on this road also gets back the probe-sidecar floor (issue 1694) it had been skipping, because the generated west application published no workspace. Measured on `demo_bringup:zephyr`: 0 re-configures, delivered knobs identical. ([#1228](https://github.com/NEWSLabNTU/nano-ros/issues/1228))
