A node package's `[package.metadata.nros.node]` (or `.component` / `.components.<Name>`) `callback_groups = [{ id = "...", tier = "..." }]` is no longer read: the group → tier binding lives in the bringup's `system.toml` since RFC-0047, and the manifest form, honoured with a `[WARN]` for one release, now fails to parse with an error naming the package. Move each binding to `[[component]] group_tiers = { <id> = "<tier>" }` on that component's entry and delete the manifest key.
