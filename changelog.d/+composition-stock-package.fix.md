A stock ROS 2 CMakeLists that builds its components with a plain `add_library(<name> SHARED ...)` (ros2/demos `composition`) now configures and links. A SHARED or MODULE library builds STATIC, so the image has one runtime. `rclcpp_components_register_nodes` and `ament_environment_hooks` are accepted. `ament_target_dependencies` works beside a `target_link_libraries` in either signature, and a hand-written main gets the platform link pass. On the std surface, `publish(std::unique_ptr<M>)` publishes. The zpico liveliness-pool message names `NROS_ZENOH_MAX_LIVELINESS`, and `check-retired-knob-spellings` reads C and C++ messages too.
