A Zephyr leaf with several images now gets the board facts of the image it builds: `nros ws board-facts` applies the leaf's own image rule (`[system] default_images`) when the configure names no image, and the Zephyr lane forwards `-DNROS_IMAGE`. An unknown-board refusal names the image being built — or every image on that board when none was chosen — instead of the first image in key order, and points at `$NROS_EXTRA_BOARD_PATH` for an out-of-tree board.
