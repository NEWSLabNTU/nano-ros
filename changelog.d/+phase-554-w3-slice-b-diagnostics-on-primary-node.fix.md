A contracted image's `/diagnostics` publisher now belongs to the image's first declared node instead of a node named after the executor's session, so `ros2 node info` shows it under that node. It opens when that node is created, and if it cannot be opened, creating the node fails with the error rather than the image running on with diagnostics only in the log. A name such as `~/cmd` is resolved against the node its entity is created on, so a C or C++ entity on a second node no longer takes the first node's name. A generated image's sizing no longer reserves an extra node slot for the reporter or the lifecycle services.
