A zenoh TRANSIENT_LOCAL subscription now reads a latched value from a publisher that appears after it, and re-reads every publisher's latched value after its session reconnects. Before, a value published once right after a nano-ros publisher was created was usually lost: the publisher declares an `@adv` liveliness token on its cache, as a stock advanced publisher does, and a subscription queries the cache again when one appears. A cache read twice never delivers a value twice.
