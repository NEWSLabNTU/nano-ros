A hosted C++ poll client's `async_send_request(shared_ptr)` returns upstream's
`FutureAndRequestId`: the future as `.future`, the request's sequence id as
`.request_id` (structured bindings work), and `share()` returning a
`SharedFutureAndRequestId` whose `future` is a `std::shared_future` every copy
of which gets the same response. `remove_pending_request` takes the request id
or either wrapper. `share()` is refused at compile time without `std::promise`.
