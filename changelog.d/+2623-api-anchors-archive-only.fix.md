A C or C++ image no longer carries the parts of the C and C++ API it never calls. Every image used to keep the whole API, for example the action server and client in a talker that only publishes. That cost about 200 KB of flash: the mps2-an385 FreeRTOS C talker drops from 631,440 to about 424,000 bytes. A function your program does call is still linked, including a C function called from C++.
