`nros build` now compares an image with its board before it generates or compiles anything, and reports every reason the image cannot build for that board at once, each with its own code and remedy: a framework the board does not boot, a build road for the image's languages, what the image's RMW needs from a board (a backend states this in `[rmw.needs]`; Cyclone needs threads and a heap), a link or network the board does not carry, a missing tool, and a vendor SDK root a board package names (`[board.sdk] root_env`) that is not set. `nros check --board <board>` runs the same comparison without building. Boards can state their memory budget in `[board.memory]`.
