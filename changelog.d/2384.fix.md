Zephyr SMP images send each line of C stdout to `printk` whole (`CONFIG_NROS_CONSOLE_WHOLE_LINES`, on by default when `CONFIG_SMP=y`), so a line printed on one core is no longer split by output from the other; the qemu_cortex_a53 core-pin marker was. ([#2384](https://github.com/NEWSLabNTU/nano-ros/issues/2384))
