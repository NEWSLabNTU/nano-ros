An out-of-tree RMW backend now builds on Zephyr through `nros build`. Its `nros-rmw.toml` states which of the nano-ros Zephyr module's backends it is built over, `[rmw.zephyr] module_backend = "zenoh" | "xrce" | "cyclonedds"` (RFC-0071 D18), and the image's Kconfig selects that one. A backend that states none is refused on Zephyr with the line to add. A Zephyr Rust image now selects the backend its `rmw` names, so a second backend the module registers can no longer make the open ambiguous. On Zephyr, `rmw` must be the backend's canonical name; an alias such as `rmw-zenoh` is refused.
