On Zephyr, a thread with a small stack can now log. The log sink used to format every record in a 1280-byte buffer on the logging thread's own stack, so a thread sized for its own work could overflow on its first log line, and every later record from every thread was then lost without a word. The sink now formats into buffers it owns, set by `CONFIG_NROS_ZEPHYR_LOG_SINK_BUFFERS` (two per CPU by default, 1280 bytes each). When they are all in use, a record is truncated rather than dropped, and the sink says so once. Setting the option to 0 restores the old behaviour.
