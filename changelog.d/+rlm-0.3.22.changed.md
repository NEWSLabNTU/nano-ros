ros-launch-manifest v0.3.22 and play_launch 0.35.0, the S3 renames (contract keys only; the model is unchanged): `functions:` is `capabilities:`, a hazard's `enters:` is `leaves:`, a client names a mode with `enters:`, a manifest level's `paths:` is `event_chains:`, rates take a unit (`min_rate: 100Hz`, `rate:`), and `supervision:` moves to the platform file. Each old spelling reads for one release. The repository's contracts are migrated with `play_launch migrate`'s S3 rewrites; nano-ros reads the model, so no reader changes.
