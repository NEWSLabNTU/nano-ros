`nros setup` now waits out a download server's outage instead of failing within seconds. When a GitHub release download answers HTTP 429 or 5xx, the fetch keeps retrying for up to about four minutes (doubling waits, at most a minute apart). A network failure such as a DNS error still gets the short retry, and a 404 still fails at once. If the outage outlasts that wait, the error says it was the host's outage, not a missing file, so the run is worth repeating.
