On the bare-metal mps2-an385 board the main stack now has a stated size, 256 KiB by default, and a guard below it. Before, a stack that grew too deep wrote over the image's statics or the C heap with no diagnostic. Now it hits a region the MPU blocks and the image stops with `nros: stack overflow`, and QEMU exits with a failure status. Raise the size with `NROS_BAREMETAL_STACK_KB`. A size too large for the image's statics fails the link and names the knob. A C or C++ image's `malloc` returns NULL before its heap reaches the stack.
