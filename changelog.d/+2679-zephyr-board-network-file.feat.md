A Zephyr image takes a board network file in `os_config` once its board declares its interface (`[board.net] interfaces`; `fvp-aemv8r-smp` and `mps2-an385-zephyr` do). `nros build` renders the resolved interface into Zephyr's `NET_CONFIG_*` / `NET_DHCPV4` as `build/nros/net/<image>.conf`, appended last to `EXTRA_CONF_FILE`, and refuses a second interface, a stated `mac` and an `os_config` fragment that sets a rendered symbol (naming both sources). An image off `qemu` with no `locator` is now refused only when its RMW descriptor states a host peer (`[rmw.host] peer` other than `"none"`), so a Cyclone DDS image is accepted (issue 2679, GitHub #4011).
