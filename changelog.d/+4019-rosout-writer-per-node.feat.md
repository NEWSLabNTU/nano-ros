In an image built with the `rosout` capability, the executor now creates one `/rosout` publisher per node and sends each log record from the publisher of the node whose logger raised it, as rcl does, so a program only logs. Rust `nros::rosout::pump` and C++ `rclcpp::rosout::Publisher` are deprecated: both still compile and work, but each adds a second publisher, so delete them. C's `rclc_rosout_publisher_init` and `rclc_rosout_pump` are not deprecated, because a node made with `rclc_node_init_default` is not in the executor's node table and still needs them. `Executor::disable_rosout_on` drops one node's publisher. ([#4019](https://github.com/NEWSLabNTU/nano-ros/pull/4019))
