A Zephyr Rust image with no IP stack (`CONFIG_NET_SOCKETS` off, for example zenoh over a UART) links again. The Rust entry calls `nros_platform_zephyr_wait_network` whatever the transport, and the symbol was compiled only with `CONFIG_NET_SOCKETS`. It is now defined in every Zephyr image and returns 0 at once when there is no stack to wait for (issue 2078).
