`nros build` now stops before configuring when the Zephyr SDK lacks the toolchain your board needs, for example the 64-bit Arm toolchain for a `qemu_cortex_a53` board on Zephyr SDK 1.0, which fetches each toolchain separately. The message names the toolchain and the command that fetches it, `<sdk>/setup.sh -t <toolchain>`. Before, the build failed later with "C compiler not found".
