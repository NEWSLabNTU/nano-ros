A FreeRTOS POSIX image whose zenoh session makes one connect attempt no longer fails at boot when the simulator's tick interrupts that connect. The TCP connect now finishes an attempt a signal interrupted, instead of reporting it as refused, on every port that shares zenoh-pico's BSD-socket connect: Linux, NuttX, FreeRTOS POSIX and Zephyr. A refused or unreachable router still fails as before, within the same budget and the same number of attempts.
