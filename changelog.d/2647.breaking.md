A `string_array` parameter's element count has its own bound, `NROS_MAX_STRING_ARRAY_LEN` (`[knobs.params] max_string_array_len`, `CONFIG_NROS_MAX_STRING_ARRAY_LEN`). `NROS_MAX_ARRAY_LEN` now bounds only bool, integer and double arrays. Every parameter store slot is as large as its largest value, and that used to be the string length times the array length whenever an image declared a string and any array, so a store of 32 slots cost about 285 KB with no string array declared. Such an image now derives the string-array bound to 0, and the same store costs about 23 KB. An image that declares a `string_array` must state the new knob, as it already states the string length. Without declarations the default stays 32 and nothing changes (issue 2647).
