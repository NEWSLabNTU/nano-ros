An `NROS_BUILD_ROOT` that the current checkout does not own is now scoped to `<root>/checkouts/<name>-<hash>`, so two checkouts (a main checkout and its worktrees, which inherit the shell) that name one build root no longer share any build-cache kind under it — fixture trees and stamps, the sizes probe, the skip ledgers, the Corrosion cargo dirs. A root inside the checkout, including the default `<checkout>/build`, is unchanged. The rule is applied once per build system (shell `nros_build_root`, Rust `nros_build_paths::build_root`, cmake `nros_checkout_scoped_root`) and replaces issue 1904's per-site scoping; a shared Corrosion cargo dir under a raw foreign root moves from a `checkout=`-keyed hash to the scoped root (issue 1921).
