`nros run` decides whether to start a zenoh router or an XRCE agent from what the image's RMW declares in its `nros-rmw.toml`, `[rmw.host] peer = "zenoh-router" | "xrce-agent" | "none"` (RFC-0071 D17), not from a list of RMW names. An out-of-tree backend that speaks zenoh now gets a router. If a backend's descriptor leaves the field out, `--router auto` refuses and names the line to add; `--router none` and `--router <locator>` still run. The run plan's link carries the fact as `host_peer`, and `--dry-run --why` shows which descriptor stated it.
