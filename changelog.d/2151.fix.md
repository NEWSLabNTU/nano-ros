A Rust image on Zephyr is provisioned and preflighted: each Zephyr board states
the Rust triple zephyr-lang-rust compiles it for and the host packages its bindgen
needs (`[board.zephyr] rust_target` / `rust_prereqs`). `nros setup` installs the
target and asks for `clang` and `libclang-dev` in a workspace with a Rust package,
and `nros build` refuses a Rust Zephyr image missing either, naming the command
(issue 2151).
