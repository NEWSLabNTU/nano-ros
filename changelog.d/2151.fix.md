A Rust image on Zephyr is provisioned and preflighted: each Zephyr board states
the Rust triple zephyr-lang-rust compiles it for, the rustup components its build
runs (`clippy`), and the host packages its bindgen needs (`[board.zephyr]
rust_target` / `rust_components` / `rust_prereqs`). `nros setup` installs the
target and components, and asks for `clang` and `libclang-dev` in a workspace
with a Rust package; `nros build` refuses a Rust Zephyr image missing any of
them, naming the command (issue 2151).
