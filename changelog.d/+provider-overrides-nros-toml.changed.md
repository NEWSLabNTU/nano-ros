Provider overrides are declared in `nros.toml` under `[workspace.overrides]` (a single-package project with no `nros.toml` keeps its root `system.toml [overrides]`); an `[overrides]` table in a package's `src/*/system.toml` is refused. The same provider in two of a workspace's source trees (`src/` and a `package_paths` entry) is now an error naming both, as colcon refuses duplicate package names, unless the workspace declares which one to use or `--allow-overriding` is given.
