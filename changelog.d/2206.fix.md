A Cortex-M0/M0+ Zephyr image (the RP2040 of `rpi_pico/rp2040/w`) now builds. The Rust lane picks `thumbv6m-none-eabi` instead of falling through to the host triple; the two Rust read-modify-write sites that needed compare-and-swap (the `log` facade bridge installer and `nros-cpp`'s drop throttle) go through `portable-atomic` like the rest of the tree; and the Zephyr module answers the `__atomic_*_4` libcalls GCC emits for ARMv6-M over Zephyr's own `atomic_*` API, so zenoh-pico links. `thumbv6m-none-eabi` joins the provisioned Rust targets, and `check no-std` plus the feature sweep compile the CAS-less slices for it.
