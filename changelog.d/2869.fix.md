A build now refuses, naming the variable and the re-configure command, when `NROS_CARGO_PROFILE`, `NROS_INTERFACE_SEARCH_PATH`, `NROS_PLATFORM_CFFI_INCLUDE` or `NROS_STACK_FLOOR` changed since its build dir was configured. Before, it silently used the configure's value. A re-configure now also picks up a changed `NROS_CARGO_PROFILE` or `CMAKE_BUILD_TYPE`; before, only the first configure read them.
