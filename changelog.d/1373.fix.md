`just check pristine-checkout` runs the fast gate tier in a clone with no
submodules checked out, which is what `git worktree add` gives you, and fails
if any gate goes red there. A gate that needs a submodule must report NOT
VERIFIED with a remedy a worktree can run, such as `just setup-worktree`. `just
ci gate` runs it after the fast tier, and `gate.yml` runs it nightly and on
manual dispatch. The fast tier is green today in a fresh worktree with no
submodules.
