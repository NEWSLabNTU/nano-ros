Two more counts now derive from what an image declares instead of being hand-set. `NROS_MAX_LIVELINESS` (Zephyr, `ZPICO_MAX_LIVELINESS`) defaults to `-1` and sizes the zenoh liveliness pool from the entity inventory: one token for the session's own node, one per node name (plus the executor's when `lifecycle` is declared), and one per publisher, subscriber, service server and service client, three of them per action client — every token THIS session declares, never the peer graph. `NROS_RUNTIME_MAX_CELL_ENTITIES` is derived as the largest single entity kind in any one component and reaches a cargo leaf through its `nros sync` sidecar and a CMake image as `NROS_DECLARED_RUNTIME_MAX_CELL_ENTITIES`, below the board rung. Both are defaults: a stated knob, and a class's explicit `ENTITY_BOUNDS`, still win. A full component cell registry is now `NodeDeclError::CellRegistryFull` and logs the knob, where it used to be the anonymous `Runtime` error.
