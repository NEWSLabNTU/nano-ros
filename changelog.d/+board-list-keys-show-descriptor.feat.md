`nros board list` lists board keys, the names a project writes as `board = "…"`, with each board's package, platform, support status and cadence. `nros board show <board>` adds every table of the board's `nros-board.toml` as written, so a section such as `[board.run.fvp]` shows up with no CLI change, and ends with a Book line. Both take `--json`, and a misspelled board name gets the nearest names.
