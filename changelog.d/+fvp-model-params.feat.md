An Arm FVP board and image can now state the model's parameters: `[board.run.fvp] params` for every image on a board, and `[image.<id>.run.fvp] params` (or `[image_defaults.run.fvp]`) for an image, applied board first, then the image, so an image overrides a board value by naming it. `[image.<id>.run] nic = { tap = "<dev>" }` now works on an FVP, and `fvp-aemv8r-smp` enables its network device in promiscuous mode, so DDS discovery works on it. Parameters bind at configure, so changing one reconfigures the image. ([details](https://github.com/NEWSLabNTU/nano-ros/pull/4194))
