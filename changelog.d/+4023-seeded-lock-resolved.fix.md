A Rust package in a workspace with no bringup builds after an `nros build --dry-run` plan of it. The plan leaves a lock seeded from the pin set, and the build took that seed for a resolved lock, skipped `cargo update`, and then failed with "cannot update the lock file … because --frozen was passed". A lock now counts as resolved only when it names its own package; the host-tool and single-package leaf roads follow the same rule.
