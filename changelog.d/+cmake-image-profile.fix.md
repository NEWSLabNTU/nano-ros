An image's `profile` now reaches a CMake build: `nros build` configures the C and C++ build type and the Rust runtime's cargo profile from it, in either spelling (`nros-relwithdebinfo` or `RelWithDebInfo`). It used to build Release whatever the image stated. A profile with no CMake build type is refused, naming `-- -DCMAKE_BUILD_TYPE=<type>`. A Zephyr image that states `profile` is refused too, because Zephyr takes its optimisation from Kconfig.
