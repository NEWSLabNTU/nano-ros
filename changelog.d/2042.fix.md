zenoh's runtime warnings, refusals and build-script messages now name the knob to raise by its canonical env spelling, for example `NROS_ZENOH_SUBSCRIBER_RING_DEPTH` or `NROS_ZENOH_MAX_LIVELINESS`. They used to name the retired `ZPICO_*` spelling, which the build now refuses, so following the advice stopped the build. `check-retired-knob-spellings` now also refuses a retired spelling in the prose of a Rust string literal.
