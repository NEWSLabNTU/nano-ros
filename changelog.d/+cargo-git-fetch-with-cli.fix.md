`nros` now sets `CARGO_NET_GIT_FETCH_WITH_CLI=true` for every cargo it runs (the cargo road, the cargo CMake and Corrosion run, west's cargo and the metadata probe), unless the variable is already set, in which case your value is kept. Cargo then fetches nano-ros's git dependencies with the `git` command instead of its built-in transport, whose TLS could fail where `git` itself worked. `nros doctor` now checks for `git` and reports a problem when it is not on `PATH`. ([details](https://github.com/NEWSLabNTU/nano-ros/pull/4140))
