The board word `threadx-qemu-riscv64` is retired: write `rv-virt-threadx` (the board's index key, cmake module and RFC-0093 name) in `[image.*] board`, `nros::main!(deploy = …)` and `nros setup`. The old word is refused with an error naming the replacement (RFC-0093 R3, issue 2101). The board crate keeps its name, `nros-board-threadx-qemu-riscv64`.
