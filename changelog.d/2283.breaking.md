Wokwi is no longer supported as an emulator twin: a board's twin must be free and open source (QEMU, Renode). The Raspberry Pi Pico W (`rpi-pico-w-zephyr`) is now a hardware-only board, flashed by UF2 with `nros flash`; `nros run` on it answers as for any real board. Removed with it: `nros setup --tool wokwi-cli` (and `wokwi-cli` from `nros setup rpi-pico-w-zephyr`), the `wokwi-pico` probe track, and the `wokwi:<board>` emulator kind and `[board.run.wokwi]` table in board descriptors, which are now refused. You can still try the Pico W in Wokwi with your own account; nano-ros does not test it (issue 2283).
