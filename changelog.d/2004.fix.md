A runtime test that runs a whole matrix of cells inside one test now prints, when it passes, the summary of which cells ran and which were out of lane. nextest discards a passing test's output, so a green over 6 of 20 cells read the same as a green over all 20. The five such tests are named in a `.config/nextest.toml` override, and `check matrix-summary-visible` derives the list from the sources (issue 2004).
