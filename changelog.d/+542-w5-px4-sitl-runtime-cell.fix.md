The PX4 SITL uORB cell is now a Runtime cell of the test matrix, run in its own lane: the hosted nightly `px4-sitl` job. No tier lane selects PX4, because the tier runners cannot build SITL, and a test gate holds that job to the recipe the cell names. `just nightly-triage` now reports a job that only one of the nightly crons schedules as red when it fails on every run that scheduled it, and names each failing job with its step.
