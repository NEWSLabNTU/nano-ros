A Rust image on a Zephyr board that gave its main thread 16 KiB (nucleo-f767zi, rpi-pico-w, fvp-aemv8r-smp) no longer halts silently after `entry up`: those boards now give main 32 KiB, which a Rust entry needs to register its nodes, and the build refuses a Rust image with less, naming the setting to raise.
