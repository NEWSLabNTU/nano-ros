The metadata probe no longer runs another workspace's harness: each harness `[[bin]]` carries a hash of its own directory, so two components with the same id get two uplifted binaries in the shared probe target dir. Under an `NROS_BUILD_ROOT` that this checkout does not own, the probe dirs and every keyed Corrosion cargo dir are now per checkout, and the sizes-header mirror reads only its own build's cargo subdir — refusing, rather than copying, a header found only in a sibling's (issue 1904).
