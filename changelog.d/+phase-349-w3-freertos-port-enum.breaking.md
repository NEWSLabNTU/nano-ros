`FREERTOS_PORT` takes upstream FreeRTOS-Kernel's port name (`GCC_ARM_CM3`, `GCC_ARM_CRX_NOGIC`, `GCC_POSIX`) on both the CMake and the cargo road, and every in-tree FreeRTOS board states its port that way. A path under `portable/` that upstream lists (`GCC/ARM_CM3`) still works, with a deprecation message naming the enum to write instead, and will be removed one release later. A vendor port that upstream does not list, such as NXP's `GCC/ARM_CR52_GIC`, has no enum, so its path stays its only spelling (phase-349 W3).
