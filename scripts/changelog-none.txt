# The after-the-fact `Changelog: none`, read by scripts/changelog-audit.py.
#
# A pull request that changes a shipped path should carry a changelog.d/
# fragment, or a `Changelog: none` trailer on one of its commits. A merged
# commit cannot gain a trailer, so a PR that merged with neither and needs no
# entry is listed here instead: `<PR number> <reason>`, one per line. A line
# with no reason credits nothing, and the audit names it.
#
# A PR that DOES need an entry gets a fragment, not a line here. A fragment
# that links the PR's page (`/pull/<N>`) credits it.
