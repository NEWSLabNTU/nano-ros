# Phase 251 — audited allowlist of build files permitted to use the linker flag
# `--allow-multiple-definition`. SINGLE SOURCE OF TRUTH for
# scripts/check-no-allow-multiple-def.py (and `just check no-allow-multiple-def`).
#
# The flag is FORBIDDEN by default: it lets two different functions with the same
# name coexist and silently binds callers to whichever copy the linker picks first
# (the #48-class wrong-copy hazard). Every surviving use is a tracked exception
# with a reason + owning issue; the target is ZERO entries.
#
# Format: <repo-relative-path> <count>   # reason (owning issue NNNN)
# <count> is the EXACT number of uses in that file: one more is a new, unaudited
# use; one fewer must lower the row (the count may only fall). `-z muldefs` is
# the same flag. Only ACTUAL uses count (a comment that merely names it does not).
