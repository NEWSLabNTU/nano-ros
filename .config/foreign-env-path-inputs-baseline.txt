# issue 1588 — FOREIGN environment variables a build script reads without
# routing them through `nros_build_paths`. A RATCHET: it may only SHRINK.
#
# Foreign means all three: no `sdk-env.just`/board-descriptor row, outside
# cargo's own namespace, and nothing in this repo sets it. So the value arrives
# from outside, and an inherited one outranks the checkout being built (1280).
#
# Each row is `<NAME>  <classification>`. The classification is what the value
# IS, because that is the thing the call site knows and no probe can infer —
# issue 1588 measured both failures of inferring it (cargo's own path-valued
# variables report as violations; paths carried as `String` are invisible to a
# type test).
#
# A row marked `path, unrouted` is a KNOWN defect of 1560's class, kept visible
# rather than fixed blind. Every run prints how many remain. The seven it was
# seeded with (the NuttX `APP_*` channel) were routed by issue 1588.
#
# A row leaves when the call site routes through `nros_build_paths::env_path`
# (or a sibling: `env_path_list` / `env_path_list_sep` for a list,
# `env_path_pairs` for `<path>=<key>` pairs, `env_path_list_file` for a file
# of paths), or when the name gains a producer in this repo and stops being
# foreign.
#
# Regenerate ONLY to record a name that is gone:
#     python3 scripts/check-foreign-env-path-inputs.py --write-baseline
FREERTOS_CFLAGS  not a path — extra compiler flags (RFC-0049 extension point)
NROS_EXECUTOR_BACKING_SECTION  not a path — a linker section NAME (RFC-0002 4.4b)
NROS_HEAP_EXHAUSTION_IS_FATAL  not a path — a boolean flag
NROS_PARAM_DECLARATION_REASON  not a path — a human-readable reason string
NROS_PARAM_DECLARATION_STATUS  not a path — a status word
NROS_ZPICO_DEBUG  not a path — a boolean flag
PKG_CONFIG_PATH  outside any checkout — a system search path; `reroot_foreign` keeps it
