# `adopt-bounded` ledger rows that do not yet name where their envelope is
# written (issue 1637).
#
# A RATCHET, not an allowlist: this file may only SHRINK. The gate
# (`scripts/api-parity.py --self-test`, on the fast line, and first thing in
# every `--check`) fails when an `adopt-bounded` row carries no `envelope` and
# is not listed here, AND when a line here stops being needed -- the row gained
# an `envelope`, left `adopt-bounded`, or no longer exists. So the debt cannot
# grow, and a stale line cannot be kept as headroom for the next one.
#
# What a line means: the row asserts "same name and contract, weaker inside an
# envelope that is stated somewhere" and nobody has yet pointed at the
# somewhere. It is NOT a finding that the envelope is missing -- issue 1637's
# archived record lists the rows that WERE re-read and whose envelope could not
# be located, which is a different and stronger statement. To clear a line:
# find where the envelope is actually documented (a doc comment, a header, the
# book), add `"envelope": {"file": ..., "text": ...}` to the row (SCHEMA.md
# "`envelope`"), and delete the line here. If it is documented nowhere, the
# row's claim is false: document the bound where a porting user will read it,
# or change the disposition. Never edit a doc comment merely so it contains a
# string this gate wants.
#
# Do not regenerate this file from the ledger: that would turn the ratchet
# into an allowlist of whatever exists today.
