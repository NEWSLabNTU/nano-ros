# The executor trigger family (phase-417 stage 3, ledger
# `c:executor_trigger_handle_t`). The built-in triggers are passed BY NAME to
# `rclc_executor_set_trigger`, and they mean what rclc's mean, so a ported
# `rclc_executor_set_trigger(&e, rclc_executor_trigger_any, NULL)` compiles and
# behaves the same. What differs is the handle array they walk: ours is
# `rclc_executor_trigger_handle_t` (entity + readiness) against rclc's
# `rclc_executor_handle_t`, which carries rclc's whole handle record. A
# hand-written rclc trigger therefore fails to compile on the handle type —
# loudly, at the function a porter wrote.
