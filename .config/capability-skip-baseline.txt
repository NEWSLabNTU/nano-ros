# Capability skips a lane is ALLOWED to take — issue 1161.
#
# A RATCHET, not an allowlist. Every line is a declaration that some host may
# legitimately lack a thing, and that skipping is the honest outcome there. A
# capability skip matching NO line is a FAILURE, so the set cannot grow by
# accident; it may shrink freely, and shrinking is the goal.
#
# WHY THIS EXISTS. `check-skip-budget` already distinguishes the three skip
# classes and prints the actionable ones. What it did not do was FAIL on any of
# them, so `check-required-features-tests` ran 7 of its 20 tests and reported
# pass — the shape issue 0584 made countable for FIXTURES ("an absent in-lane
# fixture is a hard failure, not a skip") and left open for CAPABILITIES. The
# two are the same sentence: the thing this test needs is not here, and the run
# did less than it claimed.
#
# FORMAT: one Python regular expression per line, matched against the reason
# text of a `capability`-class skip (the `[SKIPPED] …` line). Comments and blank
# lines ignored. Keep each pattern narrow enough to name ONE missing thing — a
# broad pattern re-creates the hole this file closes.
#
# Each entry states what is missing, why a host may lack it, and what would
# retire the line.

# not part of a base ROS install, so a host with ROS can still lack it. The
# router is resolved through `AMENT_PREFIX_PATH` (RFC-0075) and is deliberately
# NOT searched for on PATH, so "installed but not sourced" reads the same as
# absent — which is correct, because an unsourced router is one the loader would
# pair with the wrong `libzenohc.so` (issue 0774).
#
# RETIRES WHEN: the lanes that need it provision it, or move to a lane whose
# contract states the requirement. 13 of `check-required-features-tests`' 20

#

#
