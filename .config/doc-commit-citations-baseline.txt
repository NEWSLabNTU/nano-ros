# grow. A citation resolves only when its commit is in the DEFAULT BRANCH's
# history (issue 1205): a commit reachable only from a fetched work branch is
# not landed, and does not retire a line.

# NOT every entry is a defect, and this is the part to read before "fixing"

#
#   FOREIGN   The sentence is CORRECT and the commit is in another repository —
#             an upstream project, a submodule, another checkout. Nothing in
#             this clone will ever resolve it. Rewriting the hash would replace
#             a true sentence with a wrong one.
#
#   DEAD      The commit was in THIS repository and is gone, almost always
#             because the branch it named was rebased. This is real debt: the
#             citation points at nothing and the claim it supports can no
#             longer be checked. Fix by citing something a rebase cannot
#             invalidate — a PR number, an issue number, or a description of
#             the commit — and delete the line.
