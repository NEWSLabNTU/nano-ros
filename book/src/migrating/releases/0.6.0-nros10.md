# 0.6.0-nros10

<!-- type: reference · level: 2 -->

A project generated with 0.6.0-nros9 builds as it is: nothing needs to be
generated again.

## Edits you may need to make

- **`framework = "zephyr"` is refused.** A Zephyr board already picks the
  Zephyr entry for every image on it. Delete the `framework` line from that
  `[image.<id>]`; the image builds the same. The frameworks an image can
  still name are `owned-spin`, `rtic` and `px4`.
- **C++ alias headers use the rosidl file name.** `<pkg>/msg/<name>.hpp` now
  matches what rclcpp code includes: `float32_stamped.hpp` for
  `Float32Stamped`, `u_int8.hpp` for `UInt8`, `tf_message.hpp` for
  `TFMessage`. An include of the old spelling (`float32stamped.hpp`,
  `uint8.hpp`) no longer resolves; switch it to the new one.
- **Launch contracts take new key names.** `functions:` is `capabilities:`, a
  hazard's `enters:` is `leaves:`, a client names a mode with `enters:`, a
  manifest level's `paths:` is `event_chains:`, rates carry a unit
  (`min_rate: 100Hz`), and `supervision:` moves to the platform file. The old
  names still read in this release; `play_launch migrate` rewrites them.
- **The fault-tolerant time interval check covers every fallback level.** A hazard whose
  fallback sequence misses its deadline at any level, not only the last one,
  now fails the build. The message names the level that misses and the total
  for each level.

## Fixes

- A Rust node can use the constants a `.msg`, `.srv` or `.action` file
  declares, as in rclrs: `IslandMode::MODE_NOMINAL`.
- `nros configure` and `nros sync` find packages at any depth under `src/`,
  as in an Autoware layout (`src/<group>/<pkg>`), and under every
  `package_paths` entry. Two packages with the same name are refused, and the
  message names both folders.
- A package marked `COLCON_IGNORE`, `AMENT_IGNORE`, `NROS_IGNORE` or
  `.nros-ignore` is skipped by every command, so a package kept aside no
  longer breaks the whole workspace.
- A Zephyr Rust project from `nros new` builds on the toolchain its
  `rust-toolchain.toml` pins, so two hosts build the same code. The
  nucleo-f767zi Rust templates get a larger main stack to match.
- A C++ component in a nested namespace (`autoware::foo::Bar`) with no
  `HEADER` is found at `autoware/foo/Bar.hpp`.
