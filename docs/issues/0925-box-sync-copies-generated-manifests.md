## Symptom

Every `just build-test-fixtures` in the distrobox mirror fails during
`generate-bindings`, on a different workspace each time:

```
Error: load workspace at .../examples/workspaces/rust
  0: cargo metadata ...: failed to load manifest for workspace member
     `.../examples/workspaces/rust/build/freertos-zenoh/freertos_entry`
```

then, after clearing that one, `.../workspaces/safety/build/posix-zenoh/
native_rust_safety_listener_entry`, and so on. Four build cycles were spent on
this, ~25 min each.

## Cause

Both halves of the sync are individually right and wrong together.

`examples/workspaces/<ws>/Cargo.toml` is a BUILD ARTIFACT — phase-383 W3.a, and
it says so in its own first line:

```
# GENERATED by `nros build` (phase-383 W3.a) — DO NOT EDIT.
```

Its `members` are `build/<platform>-<rmw>/<entry>` paths, written from what the
generating host had. None of these manifests is tracked (checked: all 7 are
untracked).

`ros2-box-sync.sh` excludes `build/` at any depth — deliberately, correctly, and
with a comment explaining the trailing-slash semantics. But it does NOT exclude
the generated manifest, which is at the workspace ROOT and so is copied.

So the mirror receives a manifest naming members whose directories were never
copied. `cargo metadata` then fails on the first one, and every `nros sync` /
codegen step that loads that workspace fails with it.

## Why it recurs per-workspace

Clearing the manifests by NAME fixes only the workspace that happened to fail
first — the next build dies on the next one. Seven workspaces carry a generated
manifest (`bridge-cyclonedds bridge-xrce features realtime-rust rust safety
sizing`), and they have to be found by their `GENERATED` header, not by a list.
That is the "fix the class, not the reported site" rule, and it was violated
twice here before the header test replaced the name list.

## Fix

Exclude the generated workspace manifests in the sync, beside the `build/` rule
that already excludes what they reference — they are regenerated by `nros build`
in the mirror, from what the mirror actually has.

A path pattern is safe today (none is tracked), but the durable form keys on the
`GENERATED` header, so a workspace that later gains a hand-written root manifest
is not silently dropped.

## Not the same as issue 0759

0759 is "the box is in play, so every job runs in the box on its own tree".
This is the mirror being constructed INCONSISTENTLY: an artifact copied without
the inputs it names. Following 0759 exactly still lands here.
