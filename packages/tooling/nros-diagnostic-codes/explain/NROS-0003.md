`nros build` (or a verb that resolves images) found no `[image.<id>]` in any
bringup package of the workspace, so there is nothing to build.

An image is the buildable unit of nano-ros: one board, one RMW, and the
components that run on it. It is declared in a bringup package's
`system.toml` (a directory holding `package.xml` and `system.toml`, and no
code). A workspace whose bringup declares no image, or that has no bringup
package at all, has nothing for `nros build` to plan.

## How to fix it

Add an image to the bringup package's `system.toml`:

```toml
[image.demo]
board = "linux"
```

If the workspace has no bringup package yet, `nros new <ws> --board <board>
--template talker` shows the shape, and `nros configure --migrate` moves a
`system.toml` that sits beside a package's code into one.

## Design background

- RFC-0065 D6: a workspace with no image is refused, not built as a guess.
