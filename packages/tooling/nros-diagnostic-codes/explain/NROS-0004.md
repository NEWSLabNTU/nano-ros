An `[image.<id>]` table in `system.toml` has no `board` key, so nano-ros does
not know what to build the image for.

Every image names exactly one board. The board decides the target triple, the
RTOS, the toolchain and the network setup; nothing else in the project can
stand in for it.

## How to fix it

Add the board to the image's table:

```toml
[image.demo]
board = "mps2-an385-freertos"
```

`nros board list` prints the boards this SDK has.

## Design background

- RFC-0098 D3: an image's board comes from its `[image.<id>]` table.
